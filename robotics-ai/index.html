How it works

IPR is intentionally simple at the execution boundary: deterministic verification, fail-closed outcomes, and append-only evidence. This is the minimum viable identity layer for systems that must act in reality. 

[1] CREATE IPR
    - generate identity record (hash-only public surface)
    - optional keys for signing events

[2] ANCHOR INTEGRITY
    - compute deterministic SHA-256 over canonical form
    - store integrity value in record / receipt

[3] VERIFY (DETERMINISTIC)
    - recompute SHA-256
    - match == true ? VALID : INVALID

[4] EXECUTION GATE (FAIL-CLOSED)
    - VALID  -> EXECUTE + append event
    - INVALID -> BLOCK   + append refusal (optional)

[5] AUDIT
    - append-only chain
    - forensic trace without identity custody
