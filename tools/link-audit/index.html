HBCE Link Audit

This tool performs a defensive browser-side audit of selected public HBCE Platform routes. It checks internal links, deprecated routes, expected archival references, legacy terminology, registry v3 references, verify surfaces, schema files, operator registry tools and fail-closed remediation surfaces.

The current public spine is strict: Platform → IPR Onboarding App → Onboarding → IPR → IPR Card → JOKER-C2 → IPR AI Audit Trail → Registry / Verify → Boundary / Pilot layers. HBCE Platform is the public gateway. The IPR Onboarding App is the operational application surface. IPR is the first operational product. IPR Card is the operational access key. JOKER-C2 is the governed AI runtime demonstrator. IPR AI Audit Trail is the first MVP. Registry / Verify form the public proof layer.

The audit is curated and limited. It is not a full crawler, does not authenticate, does not bypass access controls, does not test external systems and does not prove production security, legal validity, regulated compliance, public authority approval or deployment integrity.

SCOPE

Curated route review

Checks the active public route spine, app-link references, proof routes, registry files, schemas, governance pages, pilot pages, context pages, operator registry tools and route-audit artifacts.

CLASSIFICATION

Actionable vs expected

Legacy text is actionable only when it appears in active public product surfaces. Audit reports, forbidden-field lists, schema guardrails and historical alignment notes are classified separately.

LIMIT

No certification claim

A clean result means the curated public route sample did not detect configured actionable issues. It does not certify cybersecurity, compliance, production readiness, operator qualification or legal authorization.

Results

The audit runs locally in the browser against public static routes only. Missing, broken, deprecated or actionable legacy references should be reviewed before treating the public route layer as clean.
