HBCE Link Audit

This tool performs a defensive, browser-side audit of selected public HBCE Platform pages. It checks internal links, deprecated routes, registry / verify alignment, and broken references on core public pages.

The audit is curated and limited. It is not a full crawler, does not authenticate, does not bypass access controls, and does not test external systems.

Sitemap Audit findings

Policy: defensive only · public pages only · no authentication · no secrets · fail-closed reporting

Scope

Curated public route check for HBCE core pages, registry, verify, schemas, audit files, and public policy files.

Deprecated routes

The audit flags references to declassed or legacy routes such as /entry/, /register/, /phase-1/, and old operator-specific terminology.

Limit

This tool checks public static routes only. It does not prove legal validity, security certification, or full deployment integrity.
