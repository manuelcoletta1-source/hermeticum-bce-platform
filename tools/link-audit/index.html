HBCE Link Audit

This tool performs a defensive browser-side audit of selected public HBCE Platform routes. It checks internal links, deprecated routes, legacy terminology, registry v3 references, verify surfaces, and broken public references across the current MATRIX AI Audit Trail R&D boundary.

The audit is curated and limited. It is not a full crawler, does not authenticate, does not bypass access controls, does not test external systems, and does not prove production security, legal validity, regulated compliance, public authority approval, or deployment integrity.

SCOPE

Curated route review

Checks selected public routes, registry files, verification pages, schema files, audit reports, governance pages, and MATRIX AI Audit Trail public surfaces.

DEPRECATED ROUTES

Legacy detection

Flags references to declassed or legacy routes such as /entry/, /register/, /phase-1/, /gate/, and strong operator-license terminology.

LIMIT

No certification claim

A clean result means the curated public route sample did not detect configured issues. It does not certify cybersecurity, compliance, production readiness, or legal authorization.

Results

The audit runs locally in the browser against public static routes only. Missing, broken, deprecated, or legacy references should be reviewed before treating the public route layer as clean.
