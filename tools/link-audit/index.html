HBCE Link Audit

This tool performs a defensive browser-side audit of selected public HBCE Platform routes. It checks internal links, deprecated routes, legacy terminology, registry v3 references, verify surfaces, expected guardrail patterns and broken public references across the current IPR-first public platform spine.

The current public interpretation is strict: IPR is the first operational product, IPR AI Audit Trail is the first MVP, HBCE is the governance ecosystem, JOKER-C2 is the runtime demonstrator, and MATRIX is the wider architectural framework.

The audit is curated and limited. It is not a full crawler, does not authenticate, does not bypass access controls, does not test external systems, and does not prove production security, legal validity, regulated compliance, public authority approval, or deployment integrity.

Policy: defensive only · public pages only · no authentication · no secrets · R&D reference boundary · fail-closed reporting

SCOPE

Curated route review

Checks selected public routes, registry files, verification pages, schema files, audit reports, governance pages, IPR product pages, IPR AI Audit Trail surfaces and public proof utilities.

CLASSIFICATION

Actionable vs expected

Legacy text is classified as actionable only when it appears in active public product surfaces. Tool guardrails, schema forbidden-field lists, archival audit reports and MVP alignment-history files are reported separately as expected references.

LIMIT

No certification claim

A clean result means the curated public route sample did not detect configured actionable issues. It does not certify cybersecurity, compliance, production readiness, operator qualification, or legal authorization.

Results

The audit runs locally in the browser against public static routes only. Missing, broken, deprecated, or actionable legacy references should be reviewed before treating the public route layer as clean.
