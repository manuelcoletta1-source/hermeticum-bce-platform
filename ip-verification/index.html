IP Verification (hash-only)

Questa pagina genera una prova hash-only della presenza di rete. L’IP non viene salvato né pubblicato: viene letto dal client e hashato localmente.

No custody: Hermeticum non conserva l’IP. Output: hash + timestamp + receipt locale.

Come funziona

1) Detect

Rileva l’IP pubblico dal browser (client-side).

2) Hash

Calcola SHA-256 dell’IP (e opzionale salt locale).

3) Receipt

Esporta un receipt JSON (local-first) per audit.

Genera prova

Modalità consigliata: hash-only con salt (opzionale) per ridurre correlabilità.

Salt (opzionale)

Testo libero (resta locale). Se vuoto → hash solo IP.

Collega a IPR (opzionale)

Inserisci payload_sha256 IPR per legare la prova a un’identità operativa.

Output

ip_hash_sha256: —
timestamp: —

Nota: questo receipt è “client observation”. La firma issuer (ED25519) richiede un nodo Hermeticum (server) o una procedura di firma offline.
