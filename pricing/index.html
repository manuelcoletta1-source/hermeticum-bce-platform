PRICING · EU-FIRST · HASH-ONLY

Prezzi pubblici

IPR è una identità operativa verificabile nel tempo. Il registry è append-only e la verifica è fail-closed: se non verificabile → INVALID. I prezzi separano due cose: creazione (local-first) e certificazione/registrazione (opponibilità).

CREA IPR VERIFY LAVORA CON NOI

Pubblico hash-only: nel registry non entrano dati personali, solo nickname + hash + timestamp.

Modello di validità

  • VALID (SOFT) = file coerente + match registry (nessun vincolo temporale)
  • VALID (HARD) = file coerente + match registry + finestra metrologica ±2 min (EU/CERT)
  • INVALID = registry assente/invalido, mismatch hash, file non conforme, policy fallita

La “certificazione” è il passaggio operativo che porta un IPR nel registro pubblico append-only e lo rende opponibile nel tempo.
