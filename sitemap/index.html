HBCE Platform public operational map.

This sitemap defines the current public structure of HBCE Platform. The platform is organized around a single operational spine: Platform → IPR Onboarding App → Onboarding → IPR → IPR Card → JOKER-C2 → IPR AI Audit Trail → Registry → Verify → Boundary / Governance / Documentation / Tools.

The purpose of this page is to make the public route structure readable and operationally navigable. It separates the core product path, the proof layer, the legal and governance boundary, the commercial / pilot path, the documentation layer and the audit tools.

HBCE Platform is an R&D reference surface. This sitemap does not create legal certification, official identity issuance, public authority approval, eIDAS qualification, regulated KYC / AML status, production deployment, public-sector adoption or automatic JOKER-C2 access.
