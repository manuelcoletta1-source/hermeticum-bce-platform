HBCE Platform public map.

This sitemap defines the current public structure of HBCE Platform. The platform is organized around a single operational spine: Platform → Onboarding → IPR → IPR Card → JOKER-C2 → IPR AI Audit Trail → Registry / Verify → Boundaries → Pilot paths.

The purpose of this page is to make the public route structure readable. It separates product pages, proof pages, legal / privacy / claims pages, governance pages, commercial pilot pages and contextual pages.

HBCE Platform is an R&D reference surface. This sitemap does not create legal certification, official identity issuance, public authority approval, eIDAS qualification, regulated KYC / AML status, production deployment, public-sector adoption or automatic JOKER-C2 access.
