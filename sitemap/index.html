Public R&D infrastructure map

This sitemap defines the current public structure of the HBCE Platform. The active public spine is centered on IPR as the first operational product, IPR AI Audit Trail as the first MVP, registry v3, verification, protocol references, tools, governance pages and public non-claims.

MATRIX remains the wider architectural framework. It does not replace the IPR product layer, the registry layer, the verification layer or the public proof boundary.

Pages outside this structure should be treated as historical, archival, declassed or non-operational unless explicitly linked from the current public spine.

PUBLIC BOUNDARY

This platform is presented as an R&D reference surface. It is not a public authority service, not a regulated certification system, not an eIDAS qualified trust service, not a custodial identity service, and not a production compliance framework by itself.
