1. Route classification

/join-operator/ is classified as a legacy operator onboarding route. It previously used language such as join, fee, pending license and manual approval. That wording is no longer appropriate for the current public platform state.

This page is retained only for route continuity and to prevent broken links. It should not be used as a commercial operator onboarding process, payment process, license sale, operator network admission process, or public-sector approval workflow.

2. Why the old join form is removed

The previous version generated request, order and pending license artifacts in the browser. Even if it was local-first, it could be misread as an active commercial or licensing workflow.

To avoid confusion, the active form has been removed. Operator-related discussion is now limited to R&D or future pilot interest through the safer /operator/apply/ route.
