Mappa globale dell’infrastruttura

Questa pagina descrive gli ingressi principali e i layer del nodo hermeticum-bce-platform. È una vista “alta” (da dossier): utile per orientamento, revisione e audit.

Regola base: la piattaforma non custodisce dati personali. L’unità di verifica è la prova (hash/receipt/manifest) e l’esito è deterministico PASS/FAIL.

Ingressi operativi

  • IPR — gateway identità e attivazione
  • VERIFY — verifica pubblica deterministica
  • CREATE — generazione IPR UE base (local + download)
  • AUDIT — checklist e revisione (fail-closed)

Layer (vista a 5 livelli)

L1 Identity anchor → L2 Responsibility attribution → L3 Append-only trace → L4 Public verification → L5 Interoperability

L1 — Identity anchor

Identità esterna o sovrana (non custodita). IPR definisce un formato verificabile, non un database centrale di persone.

  • /ipr/ — overview IPR
  • /standard/ipr/ — standard tecnico
  • /normative/ — mapping eIDAS2/EUDI (non-equivalenza)

L2 — Responsibility attribution

Strato di attribuzione sopra sistemi esistenti: definisce “chi risponde di cosa e quando” in modo verificabile.

  • /gate/ — metrological PASS/FAIL gate
  • /modules/ — capability modules
  • /corridors/ — canali B2G e integrazioni

L3 — Append-only trace

Traccia comparabile nel tempo. Evidence pack e registri append-only per dimostrazione ripetibile.

  • /registry/ — registry append-only
  • /network/ — rete pubblica IPR
  • /evidence/ — esempi riproducibili

L4 — Public verification

Verifica deterministica e pubblica. Esito pass/fail. Se non verificabile, invalido.

  • /verify/ — engine di verifica
  • /tech/ — checklist fail-closed
  • /openapi/ — interfacce e precheck

L5 — Interoperabilità

Integrazione con contesti reali (B2B/B2G). Nessuna sostituzione delle istituzioni: supporto tecnico all’audit.

  • /use-cases/ — scenari operativi
  • /catalog/ — con IPR / senza IPR
  • /projects/ — perimetro infrastrutturale

Mappe & riferimenti

Documenti e snapshot per revisione. Vista “da dossier” e baseline congelate.

  • /map/ — mappa semplificata ecosistema
  • /baseline/ — record di stabilizzazione
  • /changelog/ — freeze e versioni
  • NAV.html — directory canonica
