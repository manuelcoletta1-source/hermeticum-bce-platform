Come si integra (pilot minimale)

  1. Selezione unità: 1 robot/sistema (non serve fermare la produzione).
  2. Creazione IPR Unit Record: identità operativa + struttura verificabile.
  3. Audit Trail Git: eventi/upgrade concordati vengono versionati.
  4. Report tecnico: risultati + schema per scalare a flotta.
