# Security Policy

This document describes how to report potential security issues related to the HBCE infrastructure or protocol specifications.

HBCE is an experimental technological framework, and responsible disclosure of issues helps improve the system.

---

# Reporting a Vulnerability

If you discover a potential vulnerability or structural problem within the HBCE architecture or protocol documentation, please report it responsibly.

Include the following information in your report:

- description of the issue
- affected component (protocol, registry, documentation, etc.)
- potential impact
- possible suggestions for mitigation

---

# Scope

Security considerations may involve:

- protocol design issues
- registry integrity
- event structure weaknesses
- coordination layer risks
- infrastructure documentation inconsistencies

---

# Responsible Disclosure

Please avoid publicly disclosing vulnerabilities before the issue has been reviewed.

Responsible disclosure helps maintain the stability and integrity of the infrastructure.

---

# Experimental Nature

HBCE is currently an experimental infrastructure.

Security practices evolve as the architecture develops.
