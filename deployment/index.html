DEPLOYMENT · FEDERATED NODES

European Node Deployment

HBCE deploys as a federated European network of nodes. Each node supports identity validation, certified event proof, operational integrity and coordinated continuity.

What a node is

Identity gate
Validates operational identities (IPR) and operator access.
Event proof interface
Publishes hash-only public proof for certified events.
Continuity point
Maintains operational continuity across time and network layers.

Deployment model

Origin
Primary coordination node. Defines standard posture and network integrity rules.
Regional nodes
One node per region for operational verification and localized coordination.
National nodes
Federated nodes across EU countries for cross-border operational continuity.
Minimum deployment target:

- Italy: 1 node per region
- European Union: 1 node per country

Nodes are coordinated by JOKER-C2 and operate under fail-closed posture.

Operational posture

Audit-first
Every critical operation produces verifiable proof.
Fail-closed
If node integrity is not verifiable, operations block.
Hash-only public
Public exposure is limited to cryptographic proofs.

Node requirements (minimum)

A node must provide:

- operator identity verification (IPR)
- registry proof publication (hash-only)
- IO-SPACE event intake and certification pipeline
- CyberGlobal integrity controls
- availability and continuity interface to JOKER-C2

If any requirement fails, node status is not ACTIVE.
