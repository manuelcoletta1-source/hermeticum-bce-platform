Schema pubblico minimo: label + country/region/city + payload_sha256 + timestamp. Se un record non è completo o è invalido: FAIL-CLOSED.

Note operative

  • Append-only: gli operatori certificati vengono aggiunti, mai riscritti retroattivamente.
  • Hash-only: nessun dato personale pubblico.
  • Validità: il fatto di essere qui è una prova minimizzata di legittimità operativa.
  • Fail-closed: se il registry è invalido/non leggibile → nessuna autorità operativa derivabile.
