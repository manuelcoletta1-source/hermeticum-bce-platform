Operator Console

Inbox operatore per gestire richieste di certificazione/evoluzione: nessun backend, nessuna custodia. Incolli una richiesta (packet o release), la console calcola hash e produce Registry Entry pronta.

LAVORA CON NOI OPERATOR LICENSE REGISTRY VERIFY

Regola: se registry non è disponibile o JSON invalido → INVALID (fail-closed).

1) Incolla richiesta (JSON)

Incolla qui un JSON rilasciato (es. IPR_RELEASE) o un packet (es. operator license application). La console calcola SHA-256 del payload normalizzato (string JSON) e genera entry append-only.

Nota operativa: l’operatore non “inventà” dati. Verifica coerenza, produce prova hash-only, e appende entry.

2) Output operatore

SHA-256 (payload)
—
Registry Entry (append-only)
—
OPEN REGISTRY OPEN VERIFY

Sequenza: copia entry → append nel file registry/registry.json → commit/push → verifica su VERIFY.

Checklist (anti-errori)

  • nickname presente e pulito
  • payload è JSON valido
  • entry è un oggetto singolo (no doppie graffe, no virgole sbagliate)
  • append-only: mai cancellare entries esistenti
  • dopo commit, VERIFY deve trovare hash nel registry
