Issue Operator License

Operator licensing is a controlled process. The issuer manually appends proof records. If IPR is not VALID, license issuance is blocked (fail-closed).

Operator Access Verify IPR Registry

Prerequisites

VALID IPR
The operator must hold a valid IPR release file and must match the public registry proof.
Issuer authority
License issuance is performed by an authorized issuer under HBCE rules (manual append-only).
Fail-closed posture
If proof is missing or inconsistent, issuance is blocked. No partial states.

License record (hash-only proof)

An Operator License is represented publicly only by minimal proof fields:

name (public identity label) + payload_sha256 + timestamp

No public custody of personal operational data (hash-only).
Minimal public entry (example format)
{
  "name": "OPERATOR LICENSE — <PUBLIC LABEL>",
  "payload_sha256": "<64-hex sha256>",
  "timestamp": "<ISO-8601>"
}

Issuance flow (deterministic)

1) Verify IPR (file integrity + registry match)
2) Generate Operator License payload (internal, non-public)
3) Compute deterministic payload_sha256
4) Append hash-only proof to public registry (manual append-only)
5) Operator becomes eligible for node assignment

If any step fails, issuance stops (fail-closed).

Node assignment

Licensing is not enough. A licensed operator must be assigned to a node:

- Regional node (Italy)
- National node (EU)

Node assignment is recorded in the node registry and validated by integrity rules.
