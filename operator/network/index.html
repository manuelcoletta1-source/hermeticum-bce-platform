Network rules

  • Controlled scarcity: accesso iniziale limitato per garantire qualità e audit posture.
  • Territorial accountability: ogni nodo dichiara territorio e capacità operativa.
  • Audit-first: operazioni verificabili, tracciabili, coerenti con UE-first.
  • Public registry hash-only: nessuna custodia pubblica di dati personali.

Italy — regional nodes (phase 1)

Obiettivo operativo: 1 operatore per regione nella fase fondativa. Ogni regione può essere marcata come Open (disponibile) o Assigned (occupata).

Region Status Node type Action

Status “Assigned” indica che la regione è già coperta (non implica dati pubblici dell’operatore). La copertura può espandersi in fase successiva.
