2. Local proof-package builder

The tool below builds a local proof-package manifest from selected JSON artifacts. It operates entirely in the browser. It does not upload files, does not write to a backend, does not publish registry entries and does not create an official operator license.

Use only synthetic, public or expressly authorized non-sensitive artifacts. Do not select identity documents, secrets, private keys, credentials, customer data, production logs, private prompts, private outputs, private evidence or sensitive operational payloads.
