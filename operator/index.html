Operator contract

HBCE is an execution gate. If verification fails, operations are blocked. Public exposure remains hash-only, and audit evidence remains append-only. 

identity_valid == true ? EXECUTE : BLOCK
failure_mode = FAIL_CLOSED
public_surface = HASH_ONLY
evidence = APPEND_ONLY

What you implement

  • Identity verification before any high-impact execution.
  • Deterministic integrity checks (no “best effort”).
  • Append-only evidence for operator actions and system events.
  • Fail-closed control: block by default when integrity is missing.
