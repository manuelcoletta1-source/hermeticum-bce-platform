Procedura operatore (standard)

  1. Carica IPR_RELEASE del cliente.
  2. Scarica REGISTRY_ENTRY (pubblico).
  3. Carica registry.json live.
  4. Se match = NO → scarica registry.json UPDATED e committa (append-only).
  5. Dopo publish, ripeti caricando registry live aggiornato → match = YES → rilascia CERTIFICATO.
