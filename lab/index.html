0) ADS (Deterministic Decisions)

Deterministic autonomous decision engine. Emits signed decision events into the local append-only ledger. This is the “entity layer” (C): decisions become evidence.

Output: signed decision events (local ledger)

1) Kernel (Issuer)

Emits records and exports HBCE-EVIDENCE-PACK-v2. Pack-level proof is signed over pack_root_hash.

Output: Evidence Pack JSON (download)

Open Kernel →

2) Verifier (Auditor)

Independent verification: recomputes canonical preimage and validates SHA-512 root, ECDSA signature, ledger hash-chain, and per-record integrity. Returns PASS/FAIL. On PASS it stores HBCE_LAST_PACK_ROOT locally (fail-closed).

Input: Evidence Pack JSON (upload)

Open Verifier →

3) Audit Flow (Public)

Recommended external audit procedure:

  1. Run ADS and emit decisions (optional but recommended).
  2. Generate a pack in Kernel.
  3. Verify in Verifier (must PASS).
  4. Mutate one byte and verify again (must FAIL).
  5. Store the PASS report alongside the pack.

Policy: fail-closed, hash-only, append-only

Security Notes

This lab is designed for deterministic verification. It does not claim qualified timestamping by itself. If TSA/QTSP artifacts are attached later, the verifier can evolve to validate them and upgrade validation_state from ATTACHED_DECLARED to verified.

“Offline-real” means: cryptographic operations occur locally in the browser (WebCrypto). No network dependency.
