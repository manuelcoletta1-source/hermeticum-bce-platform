HBCE · AUDIT-FIRST · FAIL-CLOSED

Evidence Lab

Public, offline-real evidence workflow: generate an Evidence Pack v2 and verify it independently. Deterministic canonicalization, SHA-512 pack root, ECDSA P-256 signatures, append-only hash-chain ledger.

1) Kernel (Issuer)

Emits CQD records and exports HBCE-EVIDENCE-PACK-v2. Pack-level proof is signed over pack_root_hash.

Output: Evidence Pack JSON (download)

Open Kernel →

2) Verifier (Auditor)

Independent verification: recomputes canonical preimage and validates SHA-512 root, ECDSA signature, ledger hash-chain, and per-record integrity. Returns PASS/FAIL.

Input: Evidence Pack JSON (upload)

Open Verifier →

3) Audit Flow (Public)

Recommended external audit procedure:

  1. Generate a pack in Kernel.
  2. Verify in Verifier (must PASS).
  3. Mutate one byte and verify again (must FAIL).
  4. Store the PASS report alongside the pack.

Policy: fail-closed, hash-only, append-only

Security Notes

This lab is designed for deterministic verification. It does not claim qualified timestamping by itself. If TSA/QTSP artifacts are attached later, the verifier can evolve to validate them and upgrade validation_state from ATTACHED_DECLARED to verified.
