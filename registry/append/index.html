Append entry generator

This tool prepares a minimized public registry entry for manual append into the HBCE public registry. It does not write to the registry automatically because GitHub Pages is a static public layer.

The tool reads the public registry index and blocks deterministically: if payload_sha256 is already present → DUPLICATE_BLOCK.

R&D BOUNDARY

This page supports MATRIX AI Audit Trail R&D registry workflows. A generated entry is not a legal certificate, not public authority approval, not regulated compliance, not cybersecurity assurance, and not production authorization.

INPUT A

Load public registry entry JSON

The entry must contain minimized public fields only: payload_sha256, timestamp, subject_label, entity_type, and status.

INPUT B

Prepare manual minimized entry

Matching uses only payload_sha256. Do not enter raw personal identifiers, identity documents, secrets, credentials, private evidence, raw AI prompts, raw AI outputs, client files, or sensitive payloads.
