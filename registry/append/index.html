Append entry generator

This tool prepares a minimized public registry entry for manual append into the HBCE public registry. It does not write to the registry automatically because GitHub Pages is a static public layer.

The tool reads the public registry index and blocks deterministically: if payload_sha256 is already present → DUPLICATE_BLOCK.

Policy: EU-first · audit-first · fail-closed · hash-only · append-only · GDPR-min · no public data custody

Input

A) Load public REGISTRY_ENTRY.json

The entry must contain minimized public fields only: payload_sha256, timestamp, subject_label, entity_type, and status.

B) Or prepare manual minimized entry

Matching uses only payload_sha256. Do not enter real names, raw identifiers, identity documents, secrets, credentials, private evidence, or sensitive payloads.
