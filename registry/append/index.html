Append prepares a public proof reference.

This tool prepares a minimized public registry entry for manual append into registry/registry.json. It does not write automatically to the registry because GitHub Pages is a static public layer.

Append prepares a public proof reference. It does not certify identity, certify compliance, authorize production use, issue official identity, create eIDAS qualification, create regulated KYC / AML status or grant JOKER-C2 runtime access.

The tool reads the public registry index and blocks deterministically: if payload_sha256 is already present → DUPLICATE_BLOCK.

R&D BOUNDARY

This page supports IPR-first R&D registry workflows for IPR, IPR Card, EVT, OPC, IPR AI Audit Trail and JOKER-C2 access-boundary references. A generated entry is a manual-review candidate only.
