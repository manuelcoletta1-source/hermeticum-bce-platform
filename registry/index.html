Public Registry (Hash-only)

The HBCE registry is an append-only public ledger that stores only minimized proofs. It does not store personal data. Verification is deterministic and fail-closed.

What is stored

Minimal public entry

Required

  • payload_sha256 (required)
  • timestamp (required)
If payload_sha256 is missing → entry is invalid for verification.

Optional (minimized)

  • name (optional, strongly minimized)
  • network / kind (optional metadata)
Public identity custody is out of scope by design.

What is NOT stored

  • Personal identifiers and documents
  • Private keys, secrets, credentials
  • Raw operational logs (store privately as evidence pack)
Policy: GDPR-MIN · HASH-ONLY
Reference workflow

Canonical sequence

1) Create IPR (local release)

Generate your release file locally.

Create IPR Base

2) Register proof

Compute SHA-256 on the release bytes and append only the hash proof.

payload_sha256 = SHA-256(release_file_bytes)

3) Verify

Deterministic match: computed hash must equal registry hash. Otherwise: FAIL.
