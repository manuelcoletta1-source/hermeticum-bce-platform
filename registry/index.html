Deterministic interpretation

This viewer validates format locally. A VALID row means “required evidence exists and matches the deterministic schema”. Public surface remains hash-only. No public custody of private identity payloads.

Append-only workflow

To add a proof: generate a release → compute SHA-256 → verify deterministically → publish a minimized entry via Publish, then append it to registry.json. Never edit old entries.
