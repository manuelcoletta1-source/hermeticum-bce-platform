Registro pubblico (hash-only)

Questo registro pubblica solo prove minimizzate: nickname + payload_sha256 + timestamp. Nessun dato personale. Nessuna custodia identitaria.

Regola: append-only. Si aggiunge una nuova entry in registry.json dentro entries[]. Non si cancella, non si riscrive, non si “riordina”.

Crea (Wizard) Verify Apri registry.json

SOFT vs HARD

BASE (SOFT)

Per IPR base (es. BASE_19) non c’è finestra temporale. Se l’hash è presente qui → VALID (SOFT).

EU/CERT (HARD)

Per pacchetti certificati/istituzionali l’append deve avvenire entro ±2 min. Fuori finestra → INVALID (fail-closed).
