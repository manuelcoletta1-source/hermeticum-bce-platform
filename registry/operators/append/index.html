Append prepares a public operator reference.

This page is a local R&D builder for privacy-minimal operator reference entries intended for manual review before append to registry/operators.json.

It does not write automatically to the registry. It does not certify the operator, create an operator license, create professional qualification, create public authority approval, create regulated qualification, authorize production use or grant JOKER-C2 runtime access.

Public operator records must use minimized labels and hash-only commitments. Do not enter names, emails, phone numbers, tax codes, national identifiers, identity documents, document numbers, credentials, private keys, private evidence, raw prompts, raw outputs, client files, production logs or sensitive operational payloads.

R&D BOUNDARY

Append prepares a candidate public operator proof reference. It must be reviewed manually before insertion into registry/operators.json. A generated object is not a certification and not an authorization.
