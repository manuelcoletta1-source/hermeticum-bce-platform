Operator registry shows public proof references.

This page displays the public minimized operator registry for HBCE R&D operator proof references. It reads registry/operators.json and shows only minimized public metadata.

Operator registry shows public proof references. It does not certify operators, create operator licenses, grant professional qualification, create public authority approval, create regulated qualification, authorize production use or grant JOKER-C2 runtime access.

The public registry must not contain names, emails, phone numbers, tax codes, national identifiers, document numbers, identity documents, private evidence, credentials, private keys, raw prompts, raw outputs, client files, production logs or sensitive operational payloads.

This is not a public authority register, not a professional licensing system, not a regulated certification system, not an eIDAS qualified trust service, not a KYC / AML provider registry and not a production compliance framework. It is a public minimized R&D proof-reference surface.
