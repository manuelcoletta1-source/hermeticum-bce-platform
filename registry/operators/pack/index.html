Operator Pack groups public proof references.

This page generates a privacy-minimal PACK_MANIFEST for a public operator proof package. The pack groups public proof references such as operator reference, receipt hash, registry reference, status lookup and verification links.

Operator Pack does not store private evidence and does not certify operators. It does not create an operator license, professional qualification, public authority approval, regulated qualification, production authorization or JOKER-C2 runtime access.

Do not enter names, emails, phone numbers, tax codes, national identifiers, document numbers, identity documents, credentials, secrets, private keys, private evidence, production logs, raw prompts, raw outputs, client files or sensitive operational payloads.

R&D BOUNDARY

This builder creates a technical proof package for manual review. It does not write to registry/operators.json, does not certify an operator and does not grant access to JOKER-C2.
