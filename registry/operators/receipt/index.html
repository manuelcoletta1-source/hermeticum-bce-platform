An operator receipt proves a public operator proof reference.

This page generates a privacy-minimal receipt for an operator public proof reference. The receipt can support deterministic verification and manual append-only registry review.

It does not certify an operator, does not create an operator license, does not create professional qualification, does not create public authority approval, does not create regulated qualification, does not create production authorization and does not grant JOKER-C2 runtime access.

Do not enter real names, emails, phone numbers, tax codes, national identifiers, document numbers, identity documents, credentials, secrets, private keys, production logs, private evidence, raw AI prompts, raw AI outputs, client files or sensitive operational payloads.

R&D BOUNDARY

This receipt generator supports IPR-first R&D registry workflows. It creates technical public proof receipts only. A generated receipt must be reviewed before any manual append to registry/operators.json.
