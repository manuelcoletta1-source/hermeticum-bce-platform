Identity Primary Record

IPR Control Layer

IPR (Identity Primary Record) è il riferimento operativo primario per soggetti, sistemi e agenti artificiali. Il regime è hash-only e fail-closed: la validità deriva da prove pubbliche verificabili nel tempo.

Regime operativo

• UE-first · audit-first · fail-closed · hash-only
• Nessuna custodia dati del soggetto nel nodo pubblico (no data custody)
• Registro append-only: la validità è pubblicamente verificabile
• Assenza prova o incoerenza → INVALID

Disciplina infrastrutturale

Percorso cliente (standard)

CREATE → RECEIPT → REGISTRY → VERIFY

1) Genera payload + hash in CREATE (locale) · 2) Genera receipt · 3) Append nel registry pubblico (append-only) · 4) Verify restituisce PASS/INVALID.
