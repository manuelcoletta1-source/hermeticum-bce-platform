Service flow

Joker-C2 is not a model API. It is a governance gate above the model runtime. It enforces a minimal evidence contract and returns PASS/FAIL decisions.

1 · BIND

IPR identity + scope

Bind operator and runtime identities to IPR. Declare authority scope and policy pack.

2 · GATE

Policy & integrity checks

Validate identity, integrity, and policy prerequisites. Output is PASS/FAIL only.

3 · EXECUTE

Attestable execution

Execute only after PASS. Emit a signed, hash-linked receipt for verification.

FLOW

Client → /gate → PASS → /execute → Receipt → Verify

Minimal API contract

The interface is intentionally small. It exists to gate execution and produce verifiable receipts.

POST

/gate

Validates identity, scope, policy pack, and integrity prerequisites. Returns PASS/FAIL only.

POST

/execute

Executes a vendor-neutral AI call only after PASS. Emits a signed, hash-chained receipt.

GET

/receipt/:id

Retrieves canonical receipt for independent verification (hash + Ed25519 signature).

RECEIPT RULE

sha256(prev|input_sha256|output_sha256|policy_pack_id|ts|ipr_ai|ipr_operator) · signature payload: ascii(chain.entry) signed with ED25519.
