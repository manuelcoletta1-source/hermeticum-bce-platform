Integrate Joker-C2 in 12 minutes

This page shows a concrete, minimal integration flow: /gate → PASS → model call → /execute → receipt → verify.

Joker-C2 is vendor-neutral: OpenAI, Anthropic, xAI, local LLMs. It does not replace models — it gates execution and produces verifiable evidence receipts.

Start flow Joker-C2 Verify Pricing Home

Prerequisites: IPR activation for the operator and runtime identity. Fail-closed posture: if any check breaks, execution is denied.

Integration flow

STEP 1

Call /gate

Validate identity, scope, policy pack, and integrity prerequisites. Output is PASS/FAIL only.

STEP 2

Call your model

Execute the vendor model only if /gate returns PASS. Treat the model output as volatile until receipted.

STEP 3

Call /execute

Joker-C2 canonicalizes I/O, computes hashes, appends the chain entry, signs it (Ed25519), and returns a receipt id for verification.

FLOW LINE

Client → /gate → PASS → Model → /execute → Receipt → Verify

Deterministic receipt rule

The receipt hash is computed deterministically. Any mismatch fails closed.

RULE

sha256(prev|input_sha256|output_sha256|policy_pack_id|ts|ipr_ai|ipr_operator)
signature payload: ascii(chain.entry) signed with ED25519.

VERIFY

Verification is PASS/FAIL. A verifier checks:

  • canonicalization consistency
  • sha256 recomputation match
  • append-only chain continuity (prev)
  • Ed25519 signature validity against the published public key
