HBCE protocol (public spec)

HBCE is a deterministic identity + evidence protocol for operational systems. Private artifacts remain private. Public surface publishes minimized proofs (hash-only) in an append-only ledger.

Create IPR Base Verify Publish Registry
One path: Generate → Verify → Publish (append-only)
FAIL-CLOSED NOTICE · COMPLIANCE POSTURE
No partial validation

HBCE does not approximate. Missing evidence ⇒ INVALID. This protects auditability and prevents “soft acceptance” in safety-critical autonomy governance.

EU-first alignment (high level)

The protocol is designed to support regulatory-grade auditability: deterministic validation, minimized public exposure (hash-only), and append-only evidence trails for incident reconstruction.

Do not publish private payloads

Registry is public. Release artifacts are private. Publish only hashes and minimal labels. This prevents leakage and keeps the system compliant-by-design.
