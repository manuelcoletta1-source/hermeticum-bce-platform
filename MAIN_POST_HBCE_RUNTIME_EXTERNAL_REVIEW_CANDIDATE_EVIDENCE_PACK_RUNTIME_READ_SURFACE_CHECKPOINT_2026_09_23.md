## Layer role

This checkpoint records the HBCE External Review Candidate Evidence Pack Runtime Read Surface.

The surface consumes the Runtime Read Adapter and exposes a deterministic internal read-only surface for JOKER-C2.

The surface does not grant access, does not create authorization, does not create an authorization artifact, does not dispatch, does not execute runtime action, and does not mutate runtime state.
