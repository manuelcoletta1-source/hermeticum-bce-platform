EU Gateway

IPR (Identity Primary Record) è un codice operativo verificabile: come codice fiscale / IBAN / numero documento — ma per operatività digitale.
Abilita attribuzione, audit replicabile e continuità nel tempo per umani, AI e sistemi autonomi.
Regola: se non verificabile → INVALID (fail-closed).

Cosa abilita IPR (in termini tecnici)

Attribuzione verificabile

Un’azione digitale può essere legata a una identità operativa verificabile (hash + registry). Non “fiducia”: prova minimizzata e controllabile.

Audit replicabile

Stesso input → stesso risultato. Le verifiche sono ripetibili e pubbliche (hash-only). Se il registry non è coerente: fail-closed.

Continuità nel tempo

Evoluzione operativa gestibile con milestone e livelli (quando richiesti): senza perdere tracciabilità storica.

Pre-esecuzione (ex-ante)

Prima di eseguire: verifica. Se non verificabile, non si procede. Questo è il “gate” reale: deterministico.

Percorso canonico (unico)

CREATE → RECEIPT → REGISTRY(APPEND) → VERIFY
Il registry è append-only. La prova pubblica è hash-only. Nessuna custodia di dati personali nel portale pubblico.

Regola: se manca match nel registry → INVALID (fail-closed).
