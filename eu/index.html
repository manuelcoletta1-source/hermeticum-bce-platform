EU Gateway — IPR (Identity Primary Record)

IPR è un riferimento di identità operativa per operatività digitale verificabile nel tempo: umani, AI, sistemi autonomi e processi.
Come codice fiscale / IBAN / numero documento, ma per la precondizione tecnica di esecuzione.
Regola: se non verificabile → INVALID (fail-closed).

EU Pilot Horizon Research Press

UE-first · audit-first · fail-closed · hash-only · append-only · GDPR-min · no public data custody

Definizione operativa (per enti UE)

Cos’è

  • un riferimento di identità operativa (non civile)
  • una prova pubblica hash-only su registry append-only
  • un verify deterministico: VALID / INVALID
  • una regola ex-ante: precheck-before-action

Cosa non è

  • non è un data vault
  • non è un KYC database
  • non è “fiducia” o reputazione
  • non custodisce dati personali pubblici

La custodia dati pubblica è esclusa per design (GDPR-min).

Meccanica minima (verificabile)

Flow canonico

CREATE genera hash localmente (no custody). RECEIPT produce entry hash-only. APPEND pubblica su registry (append-only). VERIFY determina VALID/INVALID.

CREATE RECEIPT APPEND VERIFY

Pubblico: nickname/label + hash + timestamp. Privato: file release/licenza.

Stato infrastruttura

Se registry o schema non sono coerenti → fail-closed.
