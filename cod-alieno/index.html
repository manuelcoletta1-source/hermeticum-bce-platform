COD ALIENO

Specifica operativa “ultima” del motore IO-SPACE per certificazione di eventi opponibili: campi minimi, regole, output deterministico e condizioni FAIL-CLOSED.

Apri IO-SPACE VERIFY REGISTRY

Principi operativi

  • UE-FIRST · baseline UE
  • AUDIT-FIRST · ogni output ispezionabile
  • HASH-ONLY · prove minimizzate, non dati
  • APPEND-ONLY · niente riscritture
  • FAIL-CLOSED · ambiguità = blocco
  • NO PUBLIC DATA CUSTODY · niente dati personali in pubblico

Che cosa certifica IO-SPACE

IO-SPACE genera un Event Manifest e un event_hash deterministico. Un evento è opponibile quando è collegabile a un IPR valido e registrabile in append-only.

  • Decisioni operative
  • Azioni su sistemi (AI / robot / infrastrutture)
  • Comandi e transazioni tecniche
  • Emissioni/certificazioni che richiedono tracciabilità

Event Manifest — struttura canonica

Campi minimi (GDPR-min). Se serve contenuto reale, resta nel release privato. In pubblico: solo hash. 

{
  "proto": "HBCE-IO-SPACE-EVENT-v1",
  "kind": "OPPONIBLE_EVENT",
  "issuer": "HERMETICUM B.C.E. S.r.l.",
  "network": "EU",
  "policy": ["UE_FIRST","AUDIT_FIRST","FAIL_CLOSED","HASH_ONLY","APPEND_ONLY","GDPR_MIN","NO_PUBLIC_DATA_CUSTODY"],

  "actor": {
    "ipr_payload_sha256": "<64-hex sha256>"
  },

  "event": {
    "event_type": "DECISION|ACTION|TRANSACTION|COMMAND",
    "scope": "LOCAL|REGIONAL|NATIONAL|EU|GLOBAL",
    "risk_class": "R0|R1|R2|R3|R4",
    "maturity_level": "L0|L1|L2|L3|L4|L5",
    "summary": "testo breve non sensibile",
    "ref_payload_sha256": "<optional: 64-hex sha256>"
  },

  "timestamp": "2026-02-17T00:00:00Z"
}

Output deterministico

  • event_hash = sha256(canonical_json(event_manifest))
  • snippet hash-only registrabile in append-only
{
  "record_type": "STATUS_UPDATE",
  "ref_payload_sha256": "<event_hash>",
  "status": "CERTIFIED",
  "timestamp": "2026-02-17T00:00:00Z",
  "note": "IO-SPACE event certified (hash-only)"
}

FAIL-CLOSED — condizioni di blocco

  • IPR non valido / non verificabile nel registry
  • Manifest incompleto o timestamp non conforme (ISO 8601 UTC)
  • Ambiguità o contenuti sensibili in pubblico
  • Incoerenza rischio/maturità rispetto ai permessi operatore

Integrazione nel portale

  1. Attiva IPR
  2. VERIFY: deve risultare VALID
  3. Zona Operatori (gated)
  4. IO-SPACE: genera evento
  5. Append hash-only nel registry
