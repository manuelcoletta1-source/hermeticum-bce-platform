PLATFORM ARCHITECTURE · PROTOCOL SURFACE · ECOSYSTEM STRUCTURE

HBCE Spec defines the platform layer built above the IPR-CORE protocol

HBCE Spec describes how the platform is structured, how it exposes protocol-facing entry points, and how operational modules relate to the canonical protocol repository. IPR-CORE defines the identity protocol. HBCE defines the platform and ecosystem surface through which that protocol is navigated, activated, verified, and operationalized.

Open verification gateway Open activation path Open governance layer

Specification scope

PROTOCOL

What is defined elsewhere

IPR-CORE remains the canonical repository for identity structure, lifecycle, validity, versioning, evidence logic, schemas, and reference implementation.

PLATFORM

What is defined here

HBCE Spec defines platform positioning, system entry points, navigation logic, ecosystem structure, and the operational surface exposed above the protocol.

MODULES

What connects both layers

Gateways, registries, governance modules, and verification routes act as the bridge between protocol definition and real operational environments.

Canonical architecture posture

The HBCE ecosystem should be read through a strict protocol-to-platform separation. The platform does not redefine the protocol. It organizes, exposes, and contextualizes it.
