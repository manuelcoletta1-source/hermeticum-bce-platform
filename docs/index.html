Documentazione

Qui trovi la specifica pratica del flusso HBCE: creazione IPR in stile Git, emissione certificata post-pagamento, pubblicazione nel registry append-only e verifica fail-closed.

Flusso minimo (E2E)

  1. CREATE / Wizard → genera IPR_CANON.json + payload_sha256 + REGISTRY_ENTRY.json
  2. CERTIFIED (post-pagamento) → genera ISSUER_CERTIFICATE.json + OPERATIONAL_RECEIPT.json
  3. REGISTRY → append della entry (append-only)
  4. VERIFY → match pubblico = VALID (SOFT/HARD)

Hash-only: nel registry non entrano dati personali. Location-now è “quorum” e resta nel file del cliente.

IPR Git-style (campi obbligatori)

  • name (repo-name)
  • description (short README)
  • bio.primary_bio_hash (hash-only)
  • bio.location_now (country/state/region/city/district — quorum)

Certified Pack (post-pagamento)

  • ISSUER_CERTIFICATE.json — atto principale dell’issuer
  • OPERATIONAL_RECEIPT.json — ricevuta operativa firmata (non fattura)
  • IPR_RELEASE.json — release tecnica
  • REGISTRY_ENTRY.json — entry per registry pubblico

UE note: issuer con P.IVA in assegnazione (VAT pending assignment).
