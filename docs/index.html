Hub documentale istituzionale: policy operative e specifiche applicabili. In pubblico: solo prove minimizzate (hash-only).

Policy operative

  • UE-FIRST: baseline normativa UE
  • AUDIT-FIRST: verificabilità prioritaria
  • FAIL-CLOSED: se non verificabile → INVALID
  • HASH-ONLY: pubblicazione minimizzata
  • APPEND-ONLY: no riscritture
  • GDPR-MIN / NO PUBLIC DATA CUSTODY

  • Node Registry — JSON Schema

Nota di compatibilità

Viewer e registry operano in modalità deterministica. Se una fonte non è leggibile/valida → fail-closed.
