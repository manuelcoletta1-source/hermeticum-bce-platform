Documentation must follow the operational spine.

HBCE Platform documentation is organized around one sequence: verified identity → proof → governance → runtime → audit.

The platform is not an email-to-AI surface. It is an IPR Onboarding Gateway for governed AI access. Documentation therefore starts from onboarding and IPR, moves through IPR Card, proof references and verification, then reaches JOKER-C2, IPR AI Audit Trail, governance, security, legal boundaries and pilot paths.

This hub is a map of the public platform. It does not create certification, official identity, regulated KYC / AML status, eIDAS qualification, public authority approval, automatic JOKER-C2 access or production deployment.
