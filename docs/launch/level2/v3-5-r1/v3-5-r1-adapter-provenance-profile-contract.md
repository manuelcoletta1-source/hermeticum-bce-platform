# HBCE B2G Level 2 - V3.5-R1 AdapterProvenanceProfile Contract

Document ID: HBCE-L2-V3-5-R1-ADAPTER-PROVENANCE-PROFILE-CONTRACT

This artifact establishes the AdapterProvenanceProfile contract and validator baseline for V3.5-R1.

Adapters connect systems. They do not become authority, source of truth, assurance verdicts or evidentiary verdicts.

Adapter identity, version, source system, target namespace, transformation method, schema refs, runtime build and service refs are required.

Adapter events require input hash, output hash, transformation class, method ref, event time and custody_event_ref.

Export must stay within an explicit profile boundary.

Redacted export requires a redaction profile.

This contract closes L2-GAP-005 as contract and validator baseline only.

This contract does not claim full Level 2 runtime completion, B2G_CANDIDATE readiness, production readiness, public accreditation, procurement eligibility, legal validity, government endorsement or external validation completion.
