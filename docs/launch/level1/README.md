# HBCE Level 1 Launch Pack

This folder contains B2B Level 1 launch-pack documentation for the 19 January 2027 pilot-candidate release.

Current documents:

- `pricing-and-qualification.md`: pilot pricing bands, buyer qualification rules, included/excluded scope and prohibited claims.

Boundary:

- B2B only
- no defence offer
- no classified-systems offer
- no direct B2G procurement offer
- no compliance certification
- no legal liability proof
- no physical truth proof
- no production readiness claim
- no runtime pricing logic
