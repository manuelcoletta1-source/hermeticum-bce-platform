- `H.B.C.E.` means `Hermeticum Biological Cybernetic Evolution`.
- `H.B.C.E.` is the operational trust-governance architecture.
- `HBCE-*` remains the stable technical compatibility prefix for repositories, schemas, APIs, tests, evidence records and legacy document IDs.
