# HBCE Canonical Nomenclature Index

Program: `PROG-224-HBCE-CANONICAL-NOMENCLATURE-INDEX`

This index fixes the public and internal meaning of the HERMETICUM / H.B.C.E. / HBCE naming layer.

It exists to prevent semantic drift between the company identity, the operational architecture and the stable technical prefix used in repositories, schemas, APIs and evidence records.

## 1. Canonical distinction

| Name | Canonical meaning | Role | Boundary |
|---|---|---|---|
| `HERMETICUM B.C.E. S.r.l.` | Hermeticum Blindata, Computabile, Evolutiva | Company / organizational entity | Corporate identity does not itself create technical authority, certification, validation, release authorization or legal effect. |
| `H.B.C.E.` | Hermeticum Biological Cybernetic Evolution | Operational trust / governance architecture | Links biological or institutional authority to cybernetic machine capability through identity, mandate, context, policy, action and evidence. |
| `HBCE-*` | Stable technical prefix | Compatibility prefix for repositories, schemas, APIs, tests, evidence records and legacy document IDs | The prefix may remain stable even when the expanded meaning must be clarified in documentation. |
| `JOKER-C2` | Governed cognitive runtime / interface inside H.B.C.E. | Interprets, structures, proposes, explains and packages evidence | Does not originate human or institutional authority. |
| `MATRIX` | Typed operational representation | Represents namespaces, states, gates, evidence references and transition history | Representation does not create authority. |
| `OPC` | Technical verification receipt for declared control profile | Records selected control-profile verification | Not legal certification, universal truth proof or commercial release authorization. |

## 3. Required public wording

For public-facing index, README, website or partner material, use:

`HERMETICUM B.C.E. S.r.l. is the company: Blindata, Computabile, Evolutiva.`

`H.B.C.E. is the operational trust-governance architecture: Hermeticum Biological Cybernetic Evolution.`

`HBCE-* remains the stable technical prefix for repositories, schemas, APIs, tests, evidence records and legacy document IDs.`

## 4. Non-authority rule

None of the following create authority by name alone:

- HERMETICUM B.C.E. corporate identity
- H.B.C.E. architecture label
- HBCE-* technical prefix
- JOKER-C2 runtime output
- MATRIX representation
- OPC receipt
- corporate stamp / provenance marker

Authority remains human / institutional and must be expressed through bounded mandate, accepted evidence, applicable policy, declared scope and explicit GO where required.

## 5. Implementation boundary

This index is a nomenclature and semantic-control artifact.

It does not prove full MATRIX implementation, Level 1 pilot readiness, C16 completion, external validation, legal review, certification, commercial release authorization, Level 4 eligibility, dispatch execution, target receipt, execution trace or effect evidence.
