# HBCE Public Evidence Explainer v001

Program: `PROG-260-HBCE-PUBLIC-EVIDENCE-EXPLAINER`

## Purpose

This document provides a plain-language explanation of the HBCE Public Evidence Registry and its first registered baseline:

`HBCE MATRIX EG-001 T01-T37 Complete v001`

## What this is

The HBCE Public Evidence Registry is a public index of evidence baselines produced by the HBCE project.

The first registered baseline is MATRIX EG-001 T01-T37.

## Why it matters

The registry exists to make evidence externally readable.

It links public pages, JSON manifests, documentation, Git tags and GitHub Releases.
