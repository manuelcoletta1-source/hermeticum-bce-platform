Direct public reference check

This page checks whether a payload_sha256 public reference is present in the HBCE public registry index. It is a direct verification surface for the MATRIX AI Audit Trail R&D boundary.

A registry match returns PUBLIC_REFERENCE_PRESENT. No match returns NO_PUBLIC_RECORD. Invalid input returns INVALID. Invalid registry state returns NON_OPERATIONAL.

PUBLIC VERIFICATION LIMIT

A public registry match means only that a public hash reference exists. It does not certify legal validity, cybersecurity assurance, public authority approval, regulated compliance, institutional mandate, operator qualification, contractual qualification, or production authorization.

Input

You can verify a public reference in two ways: paste a JSON object containing payload_sha256, or enter payload_sha256 directly. Direct hash input takes precedence over JSON input.

INPUT 01

JSON object — optional

If the JSON contains payload_sha256, that value is used. If it does not, a local browser-side SHA-256 commitment is calculated after removing common generated hash fields. No pasted JSON is uploaded by this page.

INPUT 02

payload_sha256 — optional

Insert a 64-character lowercase SHA-256 value. If valid, this field takes precedence over the JSON input and over URL parameters.

Registry source

This verifier uses registry/registry.json as the public registry index for payload_sha256 matching. 

/hermeticum-bce-platform/registry/registry.json

Fail-closed rule

Missing input → INVALID
Invalid input → INVALID
Missing source → NON_OPERATIONAL
Invalid registry → NON_OPERATIONAL
Malformed entry → NON_OPERATIONAL
No match → NO_PUBLIC_RECORD
Valid match → PUBLIC_REFERENCE_PRESENT
