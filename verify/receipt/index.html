Receipt hash verification

This page verifies whether a local JSON file matches an expected SHA-256 receipt. The calculation is performed entirely in the browser. No file, payload, receipt, personal data, private evidence, or operational material is uploaded by this page.

A matching hash means HASH_MATCH. A mismatch means HASH_MISMATCH. Missing or invalid input means INVALID.

Policy: EU-first · audit-first · fail-closed · hash-only · client-side · no public data custody

Verification model

The verifier computes SHA-256 over the exact bytes of the selected local file and compares it with the expected receipt hash.

Privacy posture

The selected file remains local to the browser. This page does not send files to a server and does not store evidence.

Limit

A hash match proves byte-level integrity against the provided receipt. It does not replace legal, institutional, identity, or private evidence review.
