VERIFY · IPR BASE · IPR VERIFIED · EVT · OPC · FAIL-CLOSED

Verify IPR-linked evidence.

Verify is the R&D verification gateway for IPR Base records, IPR Verified proof references, EVT continuity references, OPC proof material and hash-oriented public evidence inside the HBCE ecosystem. It supports registry lookup for public hash references, verification_level interpretation and local deterministic SHA-256 comparison.

A public proof match means that a public proof reference exists. It does not prove legal identity, regulated KYC / AML compliance, eIDAS qualification, public authority validation, cybersecurity assurance or production authorization by itself.

PUBLIC VERIFICATION LIMIT

Verification can return a public-reference state and, where present, a verification level such as IPR_BASE_NOT_VERIFIED, IPR_VERIFIED_PRIVATE_CHECK or IPR_PROFESSIONAL_PILOT. These labels are technical scope indicators, not legal certification.

1. What this verifier checks

The verifier checks technical evidence. It can compare local text against an expected SHA-256 value, or it can check whether a payload_sha256 reference exists in the public HBCE registry index. This makes it useful for IPR Base records, IPR Verified public proof references, EVT-linked event payloads, OPC receipts, evidence packs and IPR AI Audit Trail reports. 

IPR record or proof artifact
→ payload_sha256 / local SHA-256 computation
→ registry reference lookup or expected-hash comparison
→ verification_level inspection
→ PASS / FAIL / NO_PUBLIC_RECORD / NON_OPERATIONAL
→ fail-closed review before validity is claimed
IPR BASE

Technical R&D record

IPR Base is a technical R&D record. Verification can check its proof references, but it does not create verified identity status by itself.

IPR VERIFIED

Private verification profile

IPR Verified may be indicated through a minimized public proof reference, but the underlying tax-code and identity-document evidence must remain in the private verification layer.

EVT / OPC

Event and proof continuity

EVT and OPC references can support operational event continuity, receipts, verification outputs and audit-oriented reconstruction.

2. Registry public reference verification

This surface checks whether a payload_sha256 commitment is present in the HBCE public registry index. The source is registry/registry.json and it must satisfy registry v3 fail-closed rules, public-data minimization rules and accepted verification_level values.

INPUT

payload_sha256 or JSON object

Insert a 64-character SHA-256 value, or paste a JSON object containing payload_sha256. If the JSON does not contain payload_sha256, the verifier computes a local SHA-256 commitment from the JSON after removing common hash-output fields.

RESULT

Public reference state

Missing match returns NO_PUBLIC_RECORD. Invalid registry state returns NON_OPERATIONAL. Ambiguous, malformed or forbidden public input returns INVALID.

3. Position in the IPR evidence flow

Verification is the reconstruction layer of the IPR evidence model. Creation prepares the record, private verification may support IPR Verified, EVT can describe the event, OPC can generate proof material, the registry can expose minimized public references, and Verify checks whether the available evidence matches. 

CREATE IPR BASE
→ OPTIONAL PRIVATE VERIFICATION FOR IPR VERIFIED
→ GENERATE EVT / OPC / EVIDENCE PACK
→ EXPOSE OR STORE HASH-ORIENTED PUBLIC REFERENCE
→ VERIFY LOCAL RECORD OR PAYLOAD_SHA256
→ INSPECT VERIFICATION_LEVEL
→ PASS / FAIL / NO_PUBLIC_RECORD / NON_OPERATIONAL
→ FAIL-CLOSED REVIEW

4. Technical deterministic verification

Paste local content exactly as stored and compare it against the expected SHA-256 value. This tool hashes the exact UTF-8 text inserted by the user. No normalization is applied.

INPUT 01

Local text

Paste the full local text to hash. This may be an IPR release object, EVT payload, OPC receipt, evidence-pack manifest, registry record or controlled proof artifact. Do not paste tax codes, identity documents, document numbers, secrets, credentials or private evidence.

Use the result carefully
