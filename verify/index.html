IPR Verification

Verifica pubblica di coerenza operativa tra file rilasciato e registry append-only. Il registry pubblico non contiene dati personali: solo nickname + hash + timestamp.

VALID (SOFT) = match registry + file coerente (nessun vincolo temporale, es. BASE_19)

VALID (HARD) = match registry + file coerente + finestra metrologica ±2 min (EU/CERT)

INVALID = mismatch hash, file non conforme, registry assente/invalido o policy HARD fallita

Hash-only: in modalità “verify by hash” l’integrità file è NOT_CHECKED.
