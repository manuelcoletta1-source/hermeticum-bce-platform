IPR Verification

Deterministic validation compares a local IPR release against a hash-only registry proof. Output is binary: PASS or FAIL. Any missing input → FAIL (fail-closed).

Inputs

Provide the minimum required data. The verifier computes SHA-256 on the exact UTF-8 bytes of the pasted release text.

1) Local release file (JSON)

Paste the content of your IPR release file (owner-controlled).

2) Registry proof (SHA-256)

Paste the expected hash from the public registry entry.

Format: lowercase hex, 64 chars. Any mismatch → FAIL.

3) Execute verification

Compute SHA-256(release_bytes) and compare to registry proof.

Normalization

The verifier computes SHA-256 on the exact bytes of the pasted JSON string (UTF-8). If you reformat or change whitespace compared to the original release file, the hash will change.

Rule: SHA-256(UTF8(release_text_as_provided))

Fail-closed

Missing release or missing expected hash is a hard failure. Any non-hex hash is a hard failure.

Missing → FAIL
Invalid format → FAIL
Mismatch → FAIL

Next steps

PASS enables operator workflows and industrial binding layers (e.g., Joker-C2). FAIL blocks execution and requires correction at the source.
