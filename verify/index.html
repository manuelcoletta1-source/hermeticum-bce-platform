VERIFY · VERIFICATION GATEWAY · DETERMINISTIC · PASS / FAIL · FAIL-CLOSED

Deterministic verification gateway

Verify is the verification gateway of the HBCE stack. It reproduces deterministic validation by comparing a local IPR Release text against a public hash-only registry proof.

Output is binary: PASS or FAIL. Missing or invalid conditions are treated as failure by design.

As-is hashing: the verifier computes SHA-256 on the exact UTF-8 bytes you paste. No normalization is applied.

POSITION IN THE STACK

In the HBCE architecture: IPR provides attribution, Joker-C2 governs execution, Registry publishes public proof, and Verify reproduces deterministic reconstruction.

Inputs

Paste the Release JSON exactly as stored in your local file. Do not reformat. The verifier computes SHA-256 on the exact UTF-8 bytes of the pasted text.
Security note: the Release text is never executed. It is hashed only.
