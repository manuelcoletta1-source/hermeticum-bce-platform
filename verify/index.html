IPR Verification

Deterministic validation compares a local IPR Release text against a hash-only registry proof. Output is binary: PASS or FAIL.

Fail-closed: any missing or invalid input → FAIL.
As-is hashing: the verifier hashes the exact UTF-8 bytes you paste (no normalization).

Normalization

This verifier does no normalization. It hashes the exact bytes you provide. This is intentional. Determinism requires byte-level equivalence.

Rule: SHA-256(UTF8(release_text_as-is))

Fail-closed

Missing Release or missing expected hash is a hard failure. Any invalid hash format is a hard failure.

Missing → FAIL
Invalid format → FAIL
Mismatch → FAIL

Next steps

PASS indicates the local Release matches a public hash-only proof. FAIL blocks execution and requires correction at the source.
