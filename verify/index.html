Deterministic verification gateway

Verify is the deterministic verification gateway of the HBCE system. It compares a local release text against an expected public proof and returns a strict binary result: PASS or FAIL.

The verifier computes SHA-256 on the exact UTF-8 bytes you provide. No normalization is applied. Missing or invalid conditions are treated as failure by design.

Open registry Open architecture Open network Open spec

Position in the system

Verify is not a standalone utility. It is the reconstruction layer of the HBCE system: identity creates attributable state, registry exposes public proof, and verification reproduces deterministic comparison.
