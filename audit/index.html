External Audit Procedure

This page documents how any independent party can verify HBCE Evidence Pack v2 without trusting the issuer. Deterministic canonicalization, SHA-512 pack root, ECDSA P-256 signature, append-only ledger chain.

1) Generate Evidence Pack

Use the Kernel (issuer) to emit events and export an Evidence Pack v2 JSON.

Open Kernel →

2) Verify Independently

Use the Verifier (auditor) to recompute canonical preimage, validate SHA-512 root, verify ECDSA signature, validate ledger chain and per-record integrity. Output is PASS/FAIL.

Open Verifier →

3) Tamper Test

Modify one byte in the JSON (e.g., a character inside phi:detail). Re-verify: it must FAIL. If it does not fail, the verifier is not trustworthy.

What is Verified

  • Pack Root: recomputed from canonical preimage (deterministic ordering).
  • Pack Signature: ECDSA P-256 signature over pack_root_hash bytes.
  • Ledger Chain: append-only hash-chain linking record hashes (tamper-evident).
  • Record Integrity: per-record payload canonical hash + signature validation.
