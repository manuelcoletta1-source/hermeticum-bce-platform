ΦΩ · INDUSTRIAL PILOT · LAPTOP MODE

Verifiable Identity & Evidence Logging for Robots / PLCs

ΦΩ is a verifiable identity + event logging layer for machines. It does not “control” your robot/PLC — it makes its actions provable. Built for EU auditability: fail-closed, hash-only, append-only.

What this solves (in plain engineering terms)

Machine identity

Each machine receives a Machine Identity Pack (MIP): stable ID + layered fingerprints + policy. Identity is linked to an append-only evidence chain.

Append-only evidence

Operational events become chained records (hash-linked). Tampering becomes detectable. No “trust me logs”.

Deterministic verification

A verifier can check a record by ID/hash and get a deterministic result: MATCH / NO MATCH plus timeline.

Pilot Mode (Laptop Mode) — 30 days

Designed for fast industrial validation: ΦΩ runs on a laptop connected to the machine network/log export (read-only). Minimum infrastructure. Maximum proof.

D1 — Evidence Log

Raw events + ΦΩ propositions + chained evidence records (append-only). Portable archive.

D2 — Verify Tool

Deterministic verification: input record/hash → output match result + traceability.

D3 — Pilot Report

Identity summary (MIP), event timeline, critical incidents, and readiness for EU audit pipelines.

Fail-closed rules (safety-by-design)

  • Hash-only: evidence is represented as hashes (no public data custody).
  • Append-only: records are chained; edits are detectable.
  • Fail-closed: if integrity/thresholds are not met → deny + log.
  • Thresholds (pilot reference): κ ≥ 0.997 · Σ ≥ 0.995 · Χτ ≤ 0.60.
