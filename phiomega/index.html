Fail-closed rules (safety-by-design)

  • Hash-only: evidence is represented as hashes (no public data custody).
  • Append-only: records are chained; edits are detectable.
  • Fail-closed: if integrity/thresholds are not met → deny + log.
  • Threshold reference: κ ≥ 0.997 · Σ ≥ 0.995 · Χτ ≤ 0.60.
  • Read-only pilot: ΦΩ ingests events; it does not control actuators in Pilot Mode.
