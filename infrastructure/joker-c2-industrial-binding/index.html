Definition (industrial, procurement-safe)

Joker-C2 Industrial Binding is an operational gate that: receives an action request, performs an identity gate and a policy gate, emits a decision (ALLOW/DENY), generates audit evidence (hash-only public proof + private receipts), and (if allowed) issues a short-lived execution token accepted by the industrial controller.

Operational flow (the moment of truth)

  1. Request: an action is requested (e.g., START_CYCLE, MOVE_HOME, CHANGE_PARAM).
  2. Identity gate: operator IPR VALID? machine IPR VALID? context IPR VALID?
  3. Policy gate: role, time window, thresholds, two-man rule, escalation rules.
  4. Decision: ALLOW / DENY with reason-code.
  5. Binding: decision is bound to identity + policy version + hashes.
  6. Execution token: short TTL token for the controller (30–120s).
  7. Evidence: public hash-only proof + private receipts for audits.

Industrial claim: show who authorized a machine action, with which identity, and prove it months later. This layer does not compete with MES/SCADA — it binds them to accountability.

Fail-closed rules (non-negotiable)

Condition Result Reason-code example
Missing or non-VALID operator IPR BLOCK IDENTITY_INVALID
Missing or non-VALID machine IPR BLOCK MACHINE_ID_INVALID
Policy version mismatch / not provable deterministically BLOCK POLICY_FAIL
Execution token expired BLOCK TOKEN_EXPIRED
Evidence pack cannot be generated BLOCK EVIDENCE_FAIL

Optional degraded mode exists only if explicitly defined (and must remain auditable). Default posture is strict fail-closed.

Industrial binding levels

Level 1

Process Binding (Pilot)

Bind operator identity to critical workflow actions (change requests, approvals, execution gates). Works with API gateways, minimal integration friction.

Level 2

Machine / Fleet Binding

Bind operator + machine identity and issue execution tokens for robots, AGVs, drones and automation cells.

Level 3

Infrastructure Gate

Enforce identity and policy at infrastructure boundaries (energy, datacenters, aerospace-grade systems). Cross-site corridors and formal audits.
