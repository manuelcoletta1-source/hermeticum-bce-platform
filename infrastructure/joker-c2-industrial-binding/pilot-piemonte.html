Pilot format

Phase 1

Discovery & risk map (1–2 weeks)

  • Pick 1–2 actions to govern (e.g., START_CYCLE, CHANGE_PARAM, OVERRIDE)
  • Define operator roles and approvals
  • Define thresholds and restricted zones
Phase 2

Integration & gating (2–4 weeks)

  • Deploy edge gateway in front of your control path
  • Enable execution tokens
  • Enable local ledger and evidence packs
Phase 3

Demo & reproducibility (1–2 weeks)

  • Run allow/deny scenarios
  • Emit hash-only proofs
  • Verify reproducibility with the verifier path
Phase 4

Scale options

  • Fleet expansion (multiple machines)
  • Operator licensing path
  • Node governance readiness
