Demo Scenarios

These scenarios show how Joker-C2 Industrial Binding operates in real environments: robotics, automation, fleets, and humanoid platforms. The goal is simple: no verified identity → no execution.

Overview Open Spec Verify Registry
Core rule: If it cannot be verified deterministically → BLOCK. Public proof is hash-only (GDPR-min). Private evidence remains under customer custody.

What happens (minimal map)

ActionRequest → Identity Gate → Policy Gate → Decision → Execution Token → Evidence Pack → Hash-only Proof

  • Identity Gate: operator IPR + machine IPR must be VALID.
  • Policy Gate: role / zone / thresholds / approvals.
  • Fail-closed: anything non-verifiable is blocked by default.

Scenarios

Scenario 1

ALLOW — Verified Operator starts a cycle

A certified operator requests START_CYCLE on an industrial robot cell. Identity and policy are valid → execution token is issued → the controller executes. 

{
  "command": "START_CYCLE",
  "operator_ref": "IPR-OP-VALID",
  "machine_ref": "IPR-M-VALID",
  "risk_class": "MED"
}

Output: ALLOW + short TTL token + evidence pack generated + hash-only proof emitted.

Scenario 2

DENY — Operator identity not VALID

A request is received, but the operator cannot be verified deterministically. Fail-closed blocks the action. 

{
  "command": "CHANGE_PARAM",
  "operator_ref": "IPR-OP-MISSING",
  "machine_ref": "IPR-M-VALID",
  "risk_class": "HIGH"
}

Output: DENY with IDENTITY_INVALID. No token is issued.

Scenario 3

REQUIRE DUAL APPROVAL — High risk action

A high-risk command requires two-man rule (supervisor approval). The system returns a pending state until both approvals are present. 

{
  "command": "OVERRIDE_SAFETY_MODE",
  "operator_ref": "IPR-OP-VALID",
  "machine_ref": "IPR-M-VALID",
  "risk_class": "HIGH"
}

Output: REQUIRE_DUAL_APPROVAL with strict TTL and audit trace.

Scenario 4

DENY — Threshold gating (torque / speed / zone)

A command implies exceeding policy thresholds (torque, speed, restricted zone). The Ethical Governor blocks before execution. 

{
  "command": "MOVE_ARM_FAST",
  "operator_ref": "IPR-OP-VALID",
  "machine_ref": "IPR-M-VALID",
  "context_ref": "IPR-ZONE-RESTRICTED",
  "risk_class": "HIGH"
}

Output: DENY with POLICY_FAIL (threshold/zone).
