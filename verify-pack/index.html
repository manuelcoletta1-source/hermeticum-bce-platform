Verify Evidence Pack

Paste the three local JSON blobs: PACK_MANIFEST, RESULT, and CHAIN_ENTRY. The verifier recomputes deterministic SHA-256 commitments in the browser and returns PASS / FAIL only.

No pasted evidence pack is uploaded by this page.

PUBLIC PROOF LIMIT

A PASS result indicates hash consistency for the provided local evidence pack. It does not replace private evidence review, legal authorization, operator qualification, identity verification, or institutional validation.

CLIENT_SIDE_ONLY
In HBCE preimage mode, the verifier removes generated hash fields before recomputing the deterministic entry hash. Invalid JSON, missing blobs, invalid hash format, or consistency mismatch produces FAIL.
FAIL-CLOSED

Failure is explicit

Missing JSON, invalid JSON, invalid expected hash, generated hash mismatch, or internal consistency mismatch never produces validity.
