What is IPR Canonical map

Canonical entry path

Follow the sequence strictly. No valid IPR → no operator access → no execution. The canonical spine is: Create → Registry → Verify.

Step 1 — Create IPR Release (local)

Generate your IPR locally. The Release file stays with the holder. This preserves the “no identity custody” principle.

Create IPR Base EU

Step 2 — Append hash-only proof to Registry

Append the deterministic hash proof to the public registry (append-only). Without registry presence, the identity cannot be validated operationally.

Open Registry

Step 3 — Deterministic Verify

Verification compares the local Release with the registry proof. Absence or mismatch → INVALID (fail-closed).

Open Verify

Step 4 — Operate (only if VALID)

Once VALID, you can access identity-gated paths (operator roles, modules, execution flows). If your deployment does not expose those pages yet, operate only within Create/Registry/Verify.

Fail-closed statement

If deterministic proof cannot be reproduced (integrity + registry presence), execution must be blocked by design. This is not optional.
