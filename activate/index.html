Canonical flow (strict)

HBCE operational validity is fail-closed. Follow the exact sequence.

Step 1 — Create
Generate the IPR Base release file client-side. This file may contain real identity data (not public).
Create IPR Base
Step 2 — Append
Append only the SHA-256 proof to the public registry (hash-only evidence). Manual commit.
Open Registry
Step 3 — Verify
Verify deterministically. If registry proof exists, generate certificate. Missing proof → INVALID.
Verify
