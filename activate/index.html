Activate Identity Primary Record

The Identity Primary Record (IPR) is the required operational identity for access to the HERMETICUM B.C.E. infrastructure. Activation generates a release file and a cryptographic fingerprint used for deterministic verification.

Activation overview

Operational identity

The IPR establishes a persistent operational identity for individuals, companies, institutions, AI systems and autonomous infrastructures.

Cryptographic verification

Each identity is linked to a SHA-256 fingerprint used for deterministic verification and registry validation.

Public hash-only registry

The public registry stores only hash proofs and timestamps. No personal data is publicly stored.

Fail-closed validation

If integrity or registry presence cannot be verified, identity status is considered invalid.

Activation process

1 — Create identity

Generate the IPR release file containing operational identity data.

2 — Generate fingerprint

A SHA-256 hash is produced for deterministic verification.

3 — Registry presence

The hash must be present in the public append-only registry.

4 — Operational access

Once verified, the identity can access licensed modules and operator network.

Registry requirement

An IPR becomes operational only when:

  • File integrity is verified
  • Hash is present in registry
  • Verification returns VALID status

If one requirement fails → status is INVALID (fail-closed model).
