Activate — Identity Infrastructure

Questa è la porta operativa unica. Tutte le operazioni (creazione IPR, operatori, verifica e registry) partono da qui. Sistema deterministico: hash-only · append-only · fail-closed.

CREATE IPR BASE (EU) CREATE OPERATOR VERIFY REGISTRY

1 · Crea IPR Base fiscale

Identità primaria europea (fiscale). Contiene dati reali (CIE/passaporto/codice fiscale). Genera file reale + hash pubblico nel registry.

OPEN CREATE BASE

2 · Attiva operatore UE

Solo con IPR Base valido. Flusso: conferma → pagamento → emissione licenza operatore.

OPEN CREATE OPERATOR

3 · Verifica deterministica

Carica file reale. Se hash presente nel registry → VALID. Se manca → INVALID (fail-closed).

OPEN VERIFY

4 · Registro pubblico

Registro append-only pubblico (hash-only). Nessun dato personale custodito.

OPEN REGISTRY

Regole operative

  • UE-first compliance
  • Hash-only public registry
  • Append-only logica
  • Fail-closed verification
  • No public custody dati personali
