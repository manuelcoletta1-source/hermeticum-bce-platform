Apri un IPR (Identity Primary Record)

Qui avviene l’onboarding come in banca: inserisci i dati richiesti per rilasciare il tuo IPR Release (file locale). Il sistema genera un’impronta SHA-256 per la verifica deterministica e prepara l’entry hash-only per il registry pubblico.
Regola: se il registry non contiene l’hash → INVALID (fail-closed).

1 — Dati cliente 2 — Genera Release 3 — Append hash-only 4 — VERIFY → VALID

Pubblico: label + payload_sha256 + timestamp (hash-only). Privato: Release con dati completi (conservato dal cliente).

Modello dati (GDPR-min)

  • Release (privato): contiene i dati completi dell’identità operativa. Deve essere conservato dal cliente.
  • Registry (pubblico): contiene solo prove hash-only + timestamp (append-only).
  • Verify: controlla integrità file + match in registry → VALID/INVALID.

Definizione: VALID IPR = FILE INTEGRITY OK + PRESENT IN REGISTRY.
