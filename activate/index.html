Attivazione IPR

Flusso canonico unico: generi localmente l’IPR, applichi la prova minimizzata nel registry append-only e verifichi pubblicamente. Se manca il match nel registry → INVALID (fail-closed).

OPEN CREATE IPR BASE OPEN REGISTRY OPEN VERIFY

Step 1 — Create

Genera IPR_RELEASE + REGISTRY_ENTRY. Tutto lato client.

Step 2 — Registry append

Appendi la prova hash-only nel registry pubblico registry/registry.json.

Step 3 — Verify

Carica l’IPR_RELEASE su VERIFY: se matcha → VALID + certificate scaricabile.
