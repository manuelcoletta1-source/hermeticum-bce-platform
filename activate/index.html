Activate your IPR (Identity Primary Record)

This page is the operational onboarding: like opening a bank account. You provide the required identity fields, then the platform generates the IPR Release file and a hash-only registry entry. Verification is deterministic and fail-closed.

Step 1 — Enter data Step 2 — Generate Release Step 3 — Append to Registry Step 4 — Verify (VALID)

Public proof is hash-only (no public personal data). If registry match is missing → INVALID.

What you receive

  • IPR Release file (your operational identity file to keep locally)
  • Receipt (issuance proof for your records)
  • Registry entry (hash-only) ready to append to the public registry
  • Deterministic verification resulting in VALID/INVALID

Operational rule: VALID IPR = FILE INTEGRITY OK + PRESENT IN REGISTRY.
