Open an IPR (Identity Primary Record)

This is the customer onboarding (bank-style). You enter identity data to issue an IPR Release (local file). The platform generates a SHA-256 fingerprint for deterministic verification and prepares the hash-only public registry entry.
Rule: if the public registry does not contain your hash → INVALID (fail-closed).

1 — Customer data 2 — Generate Release 3 — Append hash-only 4 — VERIFY → VALID

Public proof: label + payload_sha256 + timestamp (hash-only). Private: Release file with full data (kept by the customer).

Data model (GDPR-min)

  • Release (private): contains the full operational identity data. The customer must store it.
  • Registry (public): stores only hash-only proofs + timestamp (append-only).
  • Verify: checks file integrity + registry match → VALID/INVALID.

Definition: VALID IPR = FILE INTEGRITY OK + PRESENT IN REGISTRY.
