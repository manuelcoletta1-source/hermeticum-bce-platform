Procedura di attivazione (bancaria, in 4 step)

Hermeticum opera in logica audit-first e fail-closed. L’IPR è considerato VALID solo se verificabile e presente nel registry pubblico.

1) Crea IPR

Genera il tuo IPR release file (identità operativa) e la prova hash-only associata.

CREATE IPR
2) Ricevi il file

Conserva il file IPR: è la tua base operativa. La rete non richiede custodia pubblica di dati personali.

3) Verifica (fail-closed)

Verifica integrità e presenza nel registry: se non matcha → INVALID.

VERIFY
4) Registry (hash-only)

L’IPR diventa operativo quando l’entry hash-only è presente nel registry pubblico.

REGISTRY

Politiche operative (UE-first)

Audit-first · Hash-only · Append-only

La piattaforma pubblica prove minimizzate (hash + timestamp) e adotta una logica deterministica di verifica. Se il registry è invalido o non coerente, l’intero flusso opera in fail-closed.

No public data custody

Il registry pubblico non è una banca dati personale. Pubblica esclusivamente prove minimizzate necessarie alla verifica. Il file IPR rimane in possesso dell’utente/operatore.

Entità cibernetica Joker

Joker è integrata nell’attivazione

Joker supporta l’operatività: guida il percorso, integra i moduli, aumenta continuità e coerenza delle operazioni. L’accesso base è incluso nell’IPR Base EU; l’evoluzione avviene con classi operative e nodi.
