Activate (Canonical entry path)

Activate is the identity entry path of the HBCE stack. It defines the operational sequence required before governance, public proof, and deterministic verification become valid.

Create generates the local IPR Release under holder custody. Registry publishes hash-only proof. Verify reproduces deterministic validation.

Activate vs Create

ACTIVATE

Entry discipline

Activate defines the canonical entry sequence and operational discipline of the stack. It does not generate identity and does not store identity data. It is the gateway into identity-gated operation.

CREATE

Identity generation

Create generates the IPR Release file locally under holder custody. The public surface remains hash-only. Without registry proof, the identity is not operational.
