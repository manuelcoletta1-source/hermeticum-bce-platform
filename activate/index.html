Prepare IPR Verified.

Activate is the public orientation gateway for preparing IPR Verified. In this model, a human IPR becomes verified only through a private identity-verification workflow based on tax-code and valid identity-document evidence.

Accepted document categories are identity card / CIE, passport or driving license. The public registry does not store tax codes, document numbers, identity documents, scans, portraits, addresses, dates of birth or personal payloads. It stores only minimized proof references.

POSITIONING BOUNDARY

This route explains the IPR Verified preparation model. It should not be interpreted as regulated activation, official public identity issuance, legal certification, public identity registration, eIDAS qualification, qualified trust-service onboarding, KYC / AML service status or production authorization.

3. Private verification evidence

IPR Verified may use the following evidence inside a private verification workflow:

  • Tax code — used only in the private verification layer.
  • Identity card / CIE — valid document category.
  • Passport — valid document category.
  • Driving license — valid document category.
  • Private evidence package — controlled material used to generate minimized proof references.

This material must not be published to the registry, GitHub repository, public pages, public demos, public issues or public proof records.

4. Public proof minimization

The public layer may expose only minimized technical references. It must never expose the underlying identity document or tax-code payload.

PRIVATE LAYER
  • tax code;
  • identity document;
  • document number;
  • scan or image;
  • portrait image;
  • private evidence package.
PUBLIC LAYER
  • IPR reference;
  • verification level;
  • proof scope;
  • payload_sha256;
  • EVT / OPC reference;
  • timestamp;
  • status.

Public proof can support technical reconstruction. It does not create legal identity, public authority validation or regulated certification by itself.

7. Fail-closed rule

If IPR evidence cannot be reproduced through private verification, controlled material, proof references and deterministic verification, the correct state is failure or manual review. No record should be presented as verified when required evidence is missing, malformed, inconsistent or unverifiable.
