Cos’è IPR

Identità civile ≠ identità operativa

CIE/SPID/eIDAS descrivono chi sei. IPR descrive cosa può agire con prova verificabile e continuità nel tempo: persone, AI, robot, processi, organizzazioni.

IPR non sostituisce eIDAS: aggiunge un livello operativo verificabile (pre-esecuzione).

Verifica deterministica (hash-only)

Validità = match tra hash calcolato localmente e registry append-only. Se il registry è incoerente/non leggibile: FAIL-CLOSED.

Registry Verify

Percorso canonico (unico)

Un solo percorso operativo: CREATE → RECEIPT → REGISTRY(APPEND) → VERIFY.
Pubblico: nickname/name + hash + timestamp (hash-only). Privato: release/licenza.

CREATE RECEIPT APPEND VERIFY

Se manca un passaggio o non esiste match nel registry: INVALID (fail-closed).
