Cos’è (senza filosofia, solo ingegneria)

Identità civile ≠ identità operativa

CIE/SPID/eIDAS descrivono chi sei. IPR descrive cosa può agire in modo verificabile nel tempo: persone, AI, robot, organizzazioni, processi.

IPR non sostituisce eIDAS: aggiunge un livello operativo ex-ante (pre-esecuzione).

Fail-closed = sicurezza reale

Se manca la prova minima (hash) o il match nel registry, il sistema non “interpreta”: blocca. Risultato deterministico: VALID / INVALID.

“FAIL” non è errore: è protezione strutturale.

Flusso operativo (il minimo indispensabile)

Pipeline: CREATE → REGISTRY → VERIFY → CERTIFICATE

CREATE rilascia il file al cliente (IPR_RELEASE). REGISTRY pubblica una prova minimizzata (hash-only). VERIFY calcola lo SHA-256 del payload e cerca match nel registry. Se matcha → VALID e viene rilasciato il CERTIFICATO.

1 — CREATE 2 — REGISTRY 3 — VERIFY (+ Certificato)

Pubblico: name + hash + timestamp. Privato: file cliente.
