Core protocol posture

The stack follows strict design constraints. These are not aesthetic preferences. They are the conditions that make verification possible.

HASH_ONLY

Proof without public custody

Public evidence is hash-based. Sensitive public exposure is minimized by design.

APPEND_ONLY

Events cannot be rewritten

Registries grow through evidence addition, not retroactive mutation.

FAIL_CLOSED

Uncertainty blocks execution

If validity cannot be proven deterministically, the default outcome is block.

DATA MINIMIZATION

GDPR-min posture

Operational proofs are designed to avoid unnecessary personal data exposure.

STATE SEPARATION

Identity is not permission

Identity, authorization, runtime state, and evidence remain structurally separated.
