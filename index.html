Verifiable Operational Identity for Autonomous Systems

HERMETICUM B.C.E. defines a European protocol for operational identity. Humans, AI, robots, vehicles and critical infrastructure operate under deterministic verification: hash-only, append-only, fail-closed.

What HBCE Is

HBCE is a protocol-level infrastructure for assigning and verifying persistent operational identities (IPR — Identity Primary Record).

  • Root identities (human, institutional, corporate, AI)
  • Derived identities (robot, vehicle, drone, software, infrastructure)
  • Append-only public registry
  • Deterministic verification engine
  • Cryptographic signature enforcement

If verification fails, the entity is invalid. No ambiguity. Fail-closed.

Deterministic Verification (Fail-Closed)

  • If any required field is missing → INVALID
  • If SHA-256 is not 64-hex → INVALID
  • If signature is invalid → INVALID
  • If derived entity parent is not VALID → INVALID
  • Registry is append-only; history cannot be erased

Minimal CLI Flow (Reference)

node protocol/hbce-verify.reference.js protocol/hbce-registry-ledger.example.json --rebuild > protocol/hbce-registry-ledger.rebuilt.json
node protocol/hbce-sign.reference.js --keygen issuer > protocol/keys/issuer.ed25519.json
node protocol/hbce-sign.reference.js --keygen operator > protocol/keys/operator.ed25519.json
node protocol/hbce-sign.reference.js --sign-ledger protocol/hbce-registry-ledger.rebuilt.json protocol/keys/issuer.ed25519.json protocol/keys/operator.ed25519.json > protocol/hbce-registry-ledger.signed.json
node protocol/hbce-verify.reference.js protocol/hbce-registry-ledger.signed.json --check-chain
node protocol/hbce-verify.reference.js protocol/hbce-registry-ledger.signed.json --verify-entity IPR-DEV-ROBOT-0001

This reference toolchain is designed for reproducibility: same inputs → same hashes → same verification result.

Architecture

1. IPR — Identity Primary Record

Persistent operational identity. Required for access to the HBCE network. Every autonomous system must derive from a valid root.

2. HBCE Protocol

Industrial-grade identity verification standard including:

  • Hash-only public exposure
  • Append-only ledger
  • Cryptographic signatures (ED25519 baseline)
  • Derivation integrity rules
  • Deterministic verification logic

3. Operator Network

Licensed operators issue, validate and audit IPRs across local, regional, national and EU layers.
