EUROPEAN SOVEREIGN RESPONSIBILITY INFRASTRUCTURE · PUBLIC GATEWAY

Precondizione tecnica. Verifica pubblica. Fail-closed.

HERMETICUM implementa un regime di validità operativo per sistemi ad alto impatto: identità minima (IPR), registry append-only, verifica deterministica. Se non è verificabile → INVALID.

ISSUE IPR VERIFY REGISTRY STACK
Output emissione: pacchetto cliente locale + receipt append-only. Pubblico = hash-only. Privato = local-only.

Definizione

È

  • un gateway pubblico di verifica (PASS/INVALID)
  • un flusso di emissione IPR con pacchetto cliente locale
  • un registry append-only per receipt e hash
  • un modello UE-first per contesti regolati

Non è

  • un data vault o archivio documentale
  • un KYC database
  • un redirect system o una “landing marketing”
  • una validità “per fiducia”: solo verifica
Regola: percorsi mancanti o non verificabili → INVALID.
