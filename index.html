Identity infrastructure. Active. Verifiable. Append-only.

IPR (Identity Primary Record) è la radice di identità operativa verificabile per umani, AI e software. Pubblico: hash-only. Registry: append-only. Verifica: fail-closed.

EMIT IPR VERIFY REGISTRY

Regola metrologica HARD: append nel registry entro ±2 minuti dal timestamp di emissione. Fuori finestra → INVALID (fail-closed).

Cos’è

Hermeticum implementa un livello base di identità operativa: una radice verificabile opponibile nel tempo. Non è login, non è account, non è marketing: è infrastruttura.

  • Hash-only: minimizzazione pubblica
  • Append-only: storia non riscrivibile
  • Fail-closed: non verificabile → blocco
  • UE-first: standard normativo di riferimento

Come funziona

1) Generate

Emissione local-first via wizard. Download dei file IPR.

2) Done

Hash + timestamp + countdown HARD (±2 min).

3) Registry

Append hash-only nel registro pubblico append-only.

4) Verify

VALID solo se integrità file + match registry.
