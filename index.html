Cos’è IPR (definizione corta, operativa)

IPR (Identity Primary Record) è un riferimento tecnico di identità operativa: collega un soggetto (umano, AI, sistema autonomo, processo) a una prova minimizzata (hash) e a uno storico opponibile nel tempo.

  • Non è un database dati personali.
  • Non è un KYC pubblico.
  • È un meccanismo di verifica ex-ante (pre-esecuzione).

Infrastruttura: hash-only in pubblico, file privati conservati localmente. Nessuna custodia pubblica.
