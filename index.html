IPR: numero operativo digitale criptato

Due livelli, zero ambiguità: IPR-BASE EU (entrata) e IPR-OPERATORE EU (abilitazione).
Entrata per tutti. Operatività avanzata solo dopo verifica.

Attiva IPR-BASE EU Crea IPR-OPERATORE EU Software

Regola unica (semplice)

IPR-BASE EU crea la tua identità operativa (come documento/patente digitale).
IPR-OPERATORE EU è una licenza “chained” che esiste solo se la Base è VALID.

Se non verificabile → INVALID (fail-closed).

1) IPR-BASE EU — identità operativa personale

È l’entrata nel sistema. Serve per usare i software e avere una identità digitale verificabile. È come codice fiscale + carta d’identità, ma per operatività digitale.

Requisiti

  • CIE valida
  • Codice fiscale attivo
  • Dati UE verificabili
  • Email operativa

Cosa ottieni

  • File IPR (release) del cliente
  • Hash (integrità) + verifica
  • Accesso ai moduli software

Wizard: Attiva IPR-BASE EU Verifica Registry

Nota: “Attiva IPR-BASE EU” è la procedura unica per creare l’IPR personale ufficiale. Non esiste un secondo “Crea IPR” pubblico separato.

2) IPR-OPERATORE EU — licenza operativa (per pochi)

È l’abilitazione che ti rende nodo territoriale. Per ottenerla devi caricare il tuo IPR Base e risultare VALID nel registry. Se manca la Base VALID → BLOCK.

Come funziona (operativo)

  1. Apri il wizard operatore
  2. Carica il tuo file IPR_RELEASE (Base) (upload)
  3. Il browser controlla integrità (hash) e match nel registry (fail-closed)
  4. Se Base = VALID → genera Operator License + entry pubblica
