API contract (minimal)

Joker-C2 exposes a minimal governance interface. The goal is not to “be another model API”, but to gate execution and emit verifiable evidence receipts.

POST

/gate

Validates identity, scope, policy pack, and integrity prerequisites. Returns PASS/FAIL only.

POST

/execute

Executes a vendor-neutral AI call only after PASS from /gate. Emits a signed, hash-chained receipt.

GET

/receipt/:id

Retrieves the canonical receipt for independent verification (hash + Ed25519 signature).

RECEIPT RULE
