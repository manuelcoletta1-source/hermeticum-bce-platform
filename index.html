Identità operativa verificabile nel tempo

HERMETICUM B.C.E. rilascia identità operative verificabili pubblicamente: hash-only, append-only, fail-closed, UE-first.

CREA IPR VERIFY REGISTRY

Regola: se non verificabile pubblicamente (registry match) → INVALID.

Cos’è

Un’infrastruttura di identità operativa basata su prove verificabili. Il registry pubblico contiene solo nickname + hash + timestamp. Nessuna custodia dati personali.

Flusso operativo (E2E)

  1. CREATE / Wizard — genera file + hash localmente (stile Git)
  2. CERTIFIED — post-pagamento: certificato issuer + ricevuta firmata
  3. REGISTRY — append entry (append-only)
  4. VERIFY — verifica pubblica fail-closed (VALID/INVALID)

Principi

  • UE-first
  • Audit-first
  • Fail-closed
  • Hash-only
  • No identity custody
  • Append-only

Rete Operatori IPR

Il registry è append-only e non scrive da solo: la scalabilità UE avviene tramite una rete di Operatori IPR. Ogni certificazione (prima emissione o evoluzione operativa) passa da: richiesta → verifica → append → VALID.

LAVORA CON NOI VEDI PRICING

Evoluzione operativa: mensile o a rilascio. Ogni evoluzione produce un nuovo hash e deve essere registrata per restare opponibile nel tempo.
