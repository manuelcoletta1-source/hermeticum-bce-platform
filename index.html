Identità operativa verificabile per Europa

Hermeticum B.C.E. sviluppa IPR (Identity Primary Record): uno standard operativo di identità per persone, intelligenze artificiali e sistemi autonomi. Progettato per interoperabilità europea, auditabilità e automazione sicura.

Perché l’identità operativa

AI autonome, robot, agent software e infrastrutture critiche richiedono identità verificabili per autorizzazioni, responsabilità e continuità. IPR introduce uno strato persistente, auditabile e “machine-ready”.

UE-first

Interoperabilità e impostazione normativa in ottica europea.

Audit-first

La tracciabilità viene prima dell’azione: verificabile o non esiste.

Fail-closed

Se non verificabile → INVALID. Nessuna eccezione operativa.

Registry pubblico hash-only

Il registry pubblico pubblica solo prove minimizzate: hash + timestamp. Non è un database di dati personali.

Apri Registry · Apri Verify

Append-only

Il registry cresce per aggiunta (append-only). La consistenza è progettata per essere non retroattiva e auditabile.

Flusso minimo (customer flow)

Il sistema è progettato come pipeline deterministica: stesso input → stesso hash → stessa verifica.

  1. CREATE — genera payload canonico e SHA-256 in locale (no custody)
  2. RECEIPT — genera entry registry-ready (JSON)
  3. REGISTRY — append dell’entry in registry/registry.json (append-only)
  4. VERIFY — lookup live e risultato PASS/INVALID (fail-closed)

Attiva Prezzi

IPR Operatore (Licenza)

Licenza operativa territoriale per creare e gestire IPR. Accesso controllato e rete europea in costruzione. Vincolo: l’operatore deve avere un IPR Base VALID (match su registry).

  • Gate: Base VALID (integrità + registry match)
  • Emissione: create → receipt → registry → verify
  • Modello B2B/B2G (dove applicabile)
