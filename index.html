EU IPR Registry (Public)

Registro pubblico append-only. Pubblica solo prove minimizzate (hash + timestamp). Nessuna custodia pubblica di dati personali. Fail-closed.

  • IPR release file → prova hash-only
  • Verify deterministico → VALID / INVALID
  • Ledger append-only → audit permanente
  • UE-first / GDPR-min / no public data custody

JOKER-C2 Network (Distributed)

Spina dorsale operativa: 1 nodo per regione italiana + 1 nodo per nazione UE. Abilita lavoro locale, emissione IPR e mercato software per livelli di responsabilità.

  • Accesso gated: solo IPR VALID
  • Licenza operativa: accesso + responsabilità
  • Emissione IPR derivati (operatori)
  • Mercato software: studente → scienziato

Governance e sicurezza

Architettura progettata per auditabilità e minimizzazione pubblica. In pubblico: solo prove minimizzate. In caso di ambiguità: fail-closed.

  • FAIL-CLOSED: se manca integrità → INVALID
  • HASH-ONLY: pubblicazione minimizzata
  • APPEND-ONLY: nessuna riscrittura
  • UE-FIRST: standard UE come baseline
  • AUDIT-FIRST: verificabilità prioritaria
  • GDPR-MIN: minimizzazione dati
