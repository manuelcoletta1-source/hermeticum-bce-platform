Admissibility Model

HBCE does not evaluate intentions. It evaluates reproducibility and integrity. A system that cannot be replayed cannot be trusted to execute.

Admissible

Deterministic hash matches. Ledger chain intact. Evidence reproducible. Baseline compliant.

PASS = reproducible + intact + compliant

Non-admissible

Missing evidence. Hash mismatch. Non-reproducible state. Baseline violation.

FAIL = blocked (no fallback)

Deterministic Rule

If independent recomputation does not match, execution must be refused. This is not opinion. It is arithmetic.

verify(pack_hash) == recompute(pack_hash)
