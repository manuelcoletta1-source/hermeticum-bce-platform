Execution requires admissibility

HBCE determines whether an action performed by a human, AI or machine is admissible for execution. Deterministic verification, append-only evidence and fail-closed enforcement replace narrative trust.

Deterministic rule

Admissibility model

Admissible

  • Deterministic hash matches registry
  • Append-only trajectory intact
  • Integrity reproducible
  • Baseline compliant

Non-admissible

  • Missing evidence
  • Hash mismatch
  • Non reproducible state
  • Baseline violation

Non-admissible states are blocked. No silent fallback.
