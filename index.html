What this infrastructure does

IPR (Identity Primary Record) is the operational identity required to access tools and corridors inside the HERMETICUM B.C.E. infrastructure. It behaves like a “bank account opening” for digital operations: issuance produces a Release file + receipts + registry-ready hash proof.

  • Deterministic verification: VALID or INVALID (no partial trust states).
  • Fail-closed default: if registry match is missing → access is blocked.
  • GDPR-min: public registry stores only hash proofs + timestamps (no public personal data custody).
  • Scalable governance: from entry-level use to certified operator licensing and territorial node operations.
