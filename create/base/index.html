Create Base Reference

This page creates a local R&D base-reference object and hash-only public proof commitments. It is designed for the MATRIX AI Audit Trail / HBCE registry v3 boundary.

The builder runs in the browser. It does not upload private material, does not custody identity evidence, does not store private keys, and does not create legal identity certification, public authority approval, regulated compliance, eIDAS qualification, or production authorization.

PUBLIC DATA RULE

Public registry entries should contain only minimized labels and SHA-256 commitments. Do not place raw personal identifiers, identity documents, credentials, secrets, private evidence, client files, regulated identity data, production logs, private keys, or confidential payloads into public proof records.
