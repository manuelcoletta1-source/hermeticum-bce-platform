Emissione IPR (flusso canonico)

Questo è l’unico percorso operativo valido per emissione IPR in modalità pubblica: Wizard → Done → Registry → Verify. Pubblico: hash-only. Registry: append-only. Esito: fail-closed.

Regola metrologica HARD: dopo generazione devi appendere nel registry entro ±2 minuti. Fuori finestra → blocco CI (fail-closed).

Flusso canonico

1) Wizard

Generazione locale nel browser. Download immediato: IPR_RELEASE + ISSUER_CERTIFICATE + REGISTRY_ENTRY.

OPEN WIZARD

2) Done

Pagina di chiusura: hash, timestamp, countdown HARD e link diretti a Verify/Registry.

OPEN DONE

3) Registry

Append assistito: carica REGISTRY_ENTRY.json e copia il blocco pronto-incolla in entries[].

OPEN REGISTRY

4) Verify

VALID solo se: integrità file + match registry. Altrimenti INVALID (fail-closed).

OPEN VERIFY

Output (pacchetto IPR)

  • IPR_RELEASE.json — radice operativa (DNA digitale)
  • ISSUER_CERTIFICATE.json — certificazione issuer 🜏 HERMETICUM B.C.E. S.r.l.
  • REGISTRY_ENTRY.json — prova pubblica hash-only (append-only)
  • ANCHOR_RECEIPT.json — opzionale (IPFS/ETH/BTC) quando attivo

Pubblico: solo nickname + hash + timestamp. Nessuna custodia dati personali.

Principi (operativi)

  • UE-first: riferimento normativo UE
  • Audit-first: verificabilità prima dell’azione
  • Fail-closed: non verificabile → INVALID
  • Hash-only: pubblicazione minimizzata
  • Append-only: registry incrementale (storia non riscrivibile)
  • Metrological HARD: append entro ±2 min
