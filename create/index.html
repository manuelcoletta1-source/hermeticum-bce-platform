Crea il tuo IPR (senza custodia di dati personali).

Questa procedura genera un’identità operativa (IPR) in modalità local-first: i file vengono creati nel tuo browser e scaricati sul tuo dispositivo.
Il registry pubblico contiene solo prove minimizzate (nickname + hash + timestamp).
Regola: se non verificabile → INVALID (fail-closed).

Policy: UE-first · audit-first · fail-closed · hash-only · append-only · GDPR-min · no public data custody

Checklist cliente (prima di iniziare)

Cosa ti serve

  • Un nickname pubblico (non usare dati sensibili)
  • Un dispositivo dove scaricare i file (telefono/PC)
  • Capire la regola: senza registry + verify, non esiste VALID

Cosa ricevi

  • IPR_RELEASE.json (file di rilascio)
  • REGISTRY_ENTRY.json (entry hash-only pronta)
  • Se “Certified”: ISSUER_CERTIFICATE.json + OPERATIONAL_RECEIPT.json

Nota: il registry pubblico non contiene dati UE. Pubblica solo prove minimizzate.

Due modalità: Draft (locale) e Certified (opponibile)

1) Draft locale (Wizard)

Generi i file localmente e ottieni l’hash (payload_sha256). Nessun dato viene caricato su server. È il modo corretto per partire in sicurezza.

  • Chi agisce: tu (cliente)
  • Dati pubblici: solo nickname (se decidi di registrare)
  • Output: file + hash

Sequenza non negoziabile (fail-closed)

VALID esiste solo così

La verifica pubblica è deterministica: senza match nel registry append-only → INVALID.

1 — GENERA (Wizard) 2 — REGISTRY (append) 3 — VERIFY

Se salti il registry, la verify non può passare.

Cosa finisce nel registry (pubblico)

  • nickname (non sensibile)
  • payload_sha256 (prova minima)
  • timestamp (tempo evento)

Nessun campo UE (documento/CF) entra nel registry pubblico. Questa è la linea GDPR-min.

GDPR-min: cosa viene custodito (e cosa no)

No public data custody

HERMETICUM non pubblica dati personali nel registry. Il registry è un viewer di prove minimizzate (hash-only, append-only).

  • Pubblico: nickname + hash + timestamp
  • Locale (tu): eventuali campi UE nel file (se li inserisci)
  • Fail-closed: se non verificabile pubblicamente → INVALID

Nota su “Annex UE”

Se inserisci campi UE (opzionali), restano nel file sul tuo dispositivo. Non vengono pubblicati nel registry.

Questo consente un profilo “base” (solo hash-only) o un profilo “ricco” (dati locali) senza esporre dati pubblicamente.
