Crea un nuovo IPR

Questo modulo genera due artefatti sul tuo dispositivo: (1) un payload pubblico minimizzato (hash-only) da registrare nel registry, (2) un allegato UE opzionale con dati standard (solo locale) con hash separato. Nessun dato viene inviato o custodito dal nodo.

Vai a RECEIPT VERIFY REGISTRY POSITIONING

Regole (UE-first)

Hash-only pubblico

Nel registry finisce solo public_payload_sha256. Nessun dato personale.

PUBLIC = HASH ONLY

Allegato UE privato

I dati UE (nome, CF, documento, indirizzo…) restano solo locali.

PRIVATE = LOCAL ONLY

Fail-closed

Se manca un passaggio o un hash non è verificabile → INVALID.

AUDIT-FIRST
Nota: l’allegato UE serve per contesti B2G/B2B regolati (IDV/KYC), ma non viene pubblicato.

1) Nickname operativo (pubblico)

Suggerimento: stabile e sobrio (no marketing).

2) Dati UE standard (opzionali, privati)

Compila solo se ti serve opponibilità/IDV in contesti istituzionali. Questi dati non vengono pubblicati. Producono solo private_annex_sha256.

Consiglio: se non ti serve IDV, lascia vuoto tutto questo blocco.
