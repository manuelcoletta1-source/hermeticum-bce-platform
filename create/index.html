Creazione IPR

Due fasi operative: Wizard (Draft) per generare l’IPR localmente e ottenere l’hash, poi Certified post-pagamento per ottenere certificazione e ricevuta firmata.

Regola: se non verificabile pubblicamente (registry append-only) → INVALID (fail-closed).

1) Wizard (Draft) — stile Git

Inserisci nome, descrizione, bios_hash e location-now (quorum). Il sistema genera localmente: IPR_CANON.json, IPR_RELEASE.json, REGISTRY_ENTRY.json.

APRI WIZARD VERIFY REGISTRY

2) Certified (post-pagamento)

Dopo pagamento, genera il pacchetto ufficiale: ISSUER_CERTIFICATE.json (atto principale) + OPERATIONAL_RECEIPT.json (ricevuta firmata) + IPR_RELEASE.json + REGISTRY_ENTRY.json.

APRI CERTIFIED PRICING TERMS

UE note: l’issuer opera con P.IVA in assegnazione (VAT pending assignment). La ricevuta è operativa, non fattura fiscale.
