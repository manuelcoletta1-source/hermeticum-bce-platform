RECEIPT · Registry entry · Append-only

Genera la receipt per il registry

Questo step produce una entry JSON minimizzata e append-only. Pubblico significa: nickname + hash + timestamp. Nessun dato personale. Se non è verificabile → INVALID.

Apri REGISTRY VERIFY Torna a CREATE POSITIONING

Regole

Public = hash-only

La receipt pubblica non contiene dati UE. Contiene solo hash verificabile.

HASH-ONLY

Append-only

L’entry si aggiunge al registry. Nessuna riscrittura, nessun “fix” retroattivo.

APPEND-ONLY

Fail-closed

Se manca l’hash o non è valido → nessuna entry generabile (INVALID).

FAIL-CLOSED

Input

Nickname operativo

Stesso nickname usato in CREATE. Serve per operatività e audit umano.

public_payload_sha256

Incolla qui l’hash pubblico generato da CREATE. Questo è l’unico identificatore che deve finire nel registry.

—

Allegato UE privato (opzionale, NON pubblicato)

Se hai generato un annex UE (privato) in CREATE, puoi incollare qui private_annex_sha256 solo come promemoria locale. Non viene inserito nell’entry del registry.
