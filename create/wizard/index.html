Crea IPR (cliente)

Compili i dati del cliente → il sistema genera IPR_RELEASE (privato) e REGISTRY_ENTRY (pubblico minimizzato). Il cliente sarà VALID solo dopo il match in registry.

Pubblico: name + payload_sha256 + timestamp. Privato: file release con dettagli (GDPR-min: nessuna custodia pubblica).
