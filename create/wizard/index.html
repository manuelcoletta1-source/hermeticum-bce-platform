Crea IPR (stile Git)

Questo wizard genera localmente un’identità operativa in stile Git: nome, descrizione, bios_hash e location-now (quorum). Nessun dato viene inviato o custodito. Output: file canonico + hash + entry per registry.

Location = dove sei ora (quorum). Non è nazionalità. Nessun indirizzo, nessuna via, nessuna coordinata.

Input (stile Git)

Obbligatorio. Nome pubblico leggibile.
Obbligatorio. Contesto operativo.
Hash-only. Se non è 64-hex, lo convertiamo in SHA-256 localmente. Nessun dato personale in chiaro.
BASE_19 = nessun vincolo temporale (SOFT).
APRI VERIFY APRI REGISTRY

Output

  • IPR_CANON.json — payload canonico deterministico
  • IPR_RELEASE.json — release tecnica (pre-certificazione)
  • REGISTRY_ENTRY.json — entry pronta da appendere nel registry pubblico

Certificazione e ricevuta firmata vengono rilasciate nella fase “Certified” (post-pagamento).
