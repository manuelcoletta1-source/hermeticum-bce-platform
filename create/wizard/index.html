CREATE · LOCAL-FIRST · NO CUSTODY

Crea IPR (procedura UE)

Questo wizard genera un IPR nel tuo browser (lettura/scrittura locale). Nessun dato viene caricato sul server. Output: 3 file scaricabili.

Regola operativa: BASE (SOFT) = nessun vincolo temporale. EU/CERT (HARD) = append nel registry entro ±2 min (fail-closed).

Step 1 — Identità (pubblica)

Tipo entità

Scegli la classe operativa (nessuna implicazione “personale”: è solo categoria tecnica).

Joker = AI / Software. Robot/Device solo se esiste hardware fisico reale.

Nickname (pubblico)

Questo valore può comparire nel registry (hash-only). Non usare dati sensibili.

Regola: usa un nickname stabile, senza cambiare mai spazi/maiuscole dopo emissione.

Step 2 — Annex UE (opzionale, resta nel file)

Questi campi sono opzionali. Se li compili, restano nel file IPR_RELEASE.json. Non vanno nel registry pubblico (GDPR-min).

Codice Fiscale (opzionale)

Non verrà pubblicato nel registry.

Documento UE (opzionale)

Non verrà pubblicato nel registry.

Se lasci vuoto tutto l’Annex UE, l’IPR resta valido come identità operativa base.

Step 3 — Pacchetto

Selezione

In questa fase il wizard genera solo file e hash. Gli ancoraggi crypto (IPFS/EVM/BTC) sono upgrade successivo.

Output (sempre)

  • IPR_RELEASE.json — file identità + hash integrità
  • ISSUER_CERTIFICATE.json — certificazione emittente
  • REGISTRY_ENTRY.json — entry hash-only pronta per append

Regola: non modificare i file dopo emissione (altrimenti hash cambia).

Step 4 — Genera

Premi “GENERA” per creare i file. Tutto avviene localmente.

OPEN REGISTRY OPEN VERIFY

Sequenza corretta: GENERA → APPEND REGISTRY → VERIFY. Se salti registry, verify non può passare.

Risultato

Hash (payload_sha256)

Questa è la prova minima: servirà per verify e registry.

timestamp: —

Registry entry (hash-only)

Copia/incolla nel file registry/registry.json dentro entries[].

Nel registry: solo nickname + hash + timestamp. Nessun dato UE.

Download

Scarica i 3 file. Non modificarli dopo download.
