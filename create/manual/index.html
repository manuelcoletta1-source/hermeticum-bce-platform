CREATE IPR

Questo modulo genera il tuo IPR release file (il “conto operativo” della banca cibernetica) e produce una entry hash-only pronta per la registrazione nel registry pubblico.

Guida attivazione VERIFY REGISTRY
Regola fondamentale

Un IPR è considerato VALID solo se: integrità OK + match nel Registry. In assenza di match → INVALID (fail-closed).

Cosa produce CREATE

1) IPR release file (privato)

File consegnato all’utente/operatore. Contiene la struttura dell’identità operativa necessaria per operare. Va conservato: la rete non richiede custodia pubblica di dati personali.

2) Entry hash-only (pubblica)

Prova minimizzata per il registry pubblico: hash + timestamp (eventualmente nickname). Serve esclusivamente per la verifica deterministica.

Flusso operativo (lineare)

Questo è il flusso “bancario” della Banca Cibernetica Europea: prima si genera il conto (IPR), poi si verifica e si registra.

Step 1

CREATE genera file + entry hash-only.

Step 2

Conserva il file IPR (controllo in mano al titolare).

Step 3

VERIFY controlla integrità + match nel registry (fail-closed).

Step 4

REGISTRY contiene l’entry hash-only: solo allora l’IPR diventa VALID.

Politiche di rete

Audit-first

Ogni passaggio è verificabile. L’infrastruttura privilegia coerenza e tracciabilità rispetto a scorciatoie operative.

Hash-only · No public data custody

Il registry pubblico pubblica prove minimizzate. Il file IPR rimane in mano al titolare/operatore.
