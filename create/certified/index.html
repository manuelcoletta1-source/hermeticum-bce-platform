File inclusi

  • IPR_ISSUER_CERTIFICATE.json — attestazione emittente (metadati minimi)
  • IPR_OPERATIONAL_RECEIPT.json — ricevuta operativa (riferimenti + hash)
  • REGISTRY_ENTRY.json — entry hash-only pronta per append
  • PACK_MANIFEST.json — manifest con SHA-256 di tutti i file (evidence-grade)

Nota: il registry pubblico resta hash-only. Il manifest serve per provare integrità del pack offline.

Validità (non negoziabile)

  • Il pack è VALID solo se l’entry è in registry e la verify trova match
  • Se manca match → INVALID (fail-closed)

Fail-closed: errori tipici

  • hash non valido (non 64 hex) → FAIL-CLOSED
  • nickname troppo corto/lungo o con caratteri non ammessi → FAIL-CLOSED
  • entry non inserita nel registry → VERIFY non può passare
  • registry JSON incoerente → STATUS/VERIFY falliscono
