Scope

What the pilot proves

Identity-gated execution

Every execution request is permitted only if identities are valid (deterministic verification).

Policy-bound control

Requests are evaluated under explicit policy constraints. Output is ALLOW or DENY (fail-closed).

Audit evidence

Each decision emits an append-only event and produces an evidence pack hash for accountability.

Requirements

Minimal prerequisites

Access & identities

  • At least one operator IPR (human / organization)
  • At least one target IPR (robot / cell / service)
  • Registry proofs available (hash-only)

Environment

  • One controlled pilot scope (cell / line / fleet segment)
  • Read-only integration points (logs / job tickets / gateways)
  • No bypass of OEM safety constraints

Data boundary

  • Public: hash-only proofs
  • Private: evidence packs (owner-controlled)
  • GDPR-min by design
Deliverables

What is delivered

1) Binding workflow

Documented request → verify → decide → emit pipeline aligned to Joker-C2 event spec.

JOKER-C2-EVENT-v1 · append-only

2) Evidence packs

Private evidence packs with deterministic hashes suitable for registry anchoring.

evidence_pack_sha256 → registry (optional)

3) Audit report

A pilot report describing failures, denials, and allowed operations with traceability artifacts.
