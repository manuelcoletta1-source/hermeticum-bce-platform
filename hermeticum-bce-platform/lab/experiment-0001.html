EXPERIMENT-0001 — Identity-Bound Decision Trace (IBDT)

Goal: demonstrate that an agent decision can be bound to a persistent identity, written append-only, and verified deterministically in a fail-closed pipeline (hash-only public evidence).

AUDIT-FIRST FAIL-CLOSED HASH-ONLY APPEND-ONLY
Open Kernel Simulator → Open Verifier → Verify Hub → Registry Hub →

Hypothesis

A decision emitted by an autonomous agent becomes accountable if (and only if) it is: identity-bound, trace-recorded, and independently verifiable.

This is a working hypothesis. The experiment is designed to falsify it: any missing proof → INVALID.

Inputs

Input Meaning
Identity Keys Local keypair used to sign the decision event. If missing → fail-closed.
Scenario Named test scenario (e.g., robot safety, autonomy constraint).
Vector Comma-separated numbers representing sensor / state features.
N decisions Number of events emitted for the run.

Outputs

Output Acceptance criteria
Ledger Entry Append-only entry exists after the run; includes timestamp + payload hash.
Signature Proof Event includes a signature verifiable with the public key.
Deterministic Verify Verifier returns VALID only if hashes + signature match exactly.
Fail-Closed Any missing identity keys, missing hash, or mismatch → INVALID (no soft pass).

Procedure (Replicable)

  1. Open the Kernel Simulator. Initialize identity keys (required).
    If the UI shows “MISSING IDENTITY KEYS” the experiment is NOT running.
  2. Choose a Scenario and set a Vector (e.g., 1,0,1,0,3).
  3. Run N decisions and emit events to the ledger.
  4. Open the Verifier and validate the run.
    Expected: VALID only if identity + hash + signature chain is intact.
  5. Repeat with a tiny change (e.g., vector last number +1). Output must change. Old proof must not validate the new payload.

Failure Modes (Designed)

  • No identity keys → INVALID (fail-closed).
  • No payload hash → INVALID (hash-only).
  • Signature mismatch → INVALID (integrity breach).
  • Ledger write missing → run considered non-existent for audit.

In HBCE Lab, the system is allowed to be brutal: no proof = no event.

Why this matters (in plain engineering)

Robotics, autonomous fleets, critical infrastructure, and AI governance all converge on the same missing primitive: persistent operational identity. EXPERIMENT-0001 is the minimal proof that an “agent decision” can carry an identity-anchored, verifiable, audit-ready trace — without public custody of private data.
