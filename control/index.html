Operational Control Console

Remote OPC packs. Deterministic mode gate. Payload SHA-256 enforced. If evidence is missing, the system does not “degrade”. It halts.

Mode Switch

E-STOP is not a vote. Not a suggestion. It is a deterministic override.

Policy Pack (Remote OPC)

Packs are fetched from the OPC repository. If fetch fails, structure is invalid, or SHA-256 mismatches: DENY + HOLD.

Integrity scheme: HBCE-PAYLOAD-SHA256-CANONICAL-v1. Hash is computed over the pack payload (pack minus integrity) after canonical key ordering.

Local Append-Only Ledger

Every transition produces an event record. No edits. No deletions. If the environment is inconsistent: the ledger shows the denial.

WARNING: This console is intentionally strict. It does not “try again”. It does not guess. Missing evidence or hash mismatch ⇒ HALT.
