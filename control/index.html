No joystick. No continuous motion commands. Only MODE transitions under remote OPC policy packs. If evidence is missing, the system does not “degrade”. It halts.

Local Append-Only Ledger

Every transition produces an event record. No edits. No deletions. If the environment is inconsistent: the ledger shows the denial.

WARNING: This console is intentionally strict. It does not “try again”. It does not guess. If policy evidence is missing, the only safe output is HALT.
