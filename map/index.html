Livelli operativi

Level 0

Entry — IPR Base EU

Baseline tecnica. Senza Base VALID non esiste nessun livello successivo.

  • Scopo: identità operativa minima
  • Prova pubblica: hash-only su registry append-only
  • Regola: no match → INVALID

Level 1

Operator — Licenza chained

Operatore = licenza collegata a una Base VALID. Senza Base in registry → BLOCK.

  • Scopo: emissioni/attivazioni in rete
  • Tooling: workstation + append tool
  • Vincolo: audit richiesto per livelli superiori
Create Operator Workstation
Level 2

Coordinator — Scala territoriale

Coordinamento rete: audit, requisiti, qualità operativa. Mantiene coerenza e riduce rischio sistemico.

  • Scopo: governo operativo di cluster territoriali
  • Output: procedure + evidenze verificabili
  • Vincolo: policy + audit obbligatori
Control Governance
Level 3

Node — Nodo operativo

Nodo = unità infrastrutturale di rete (territorio o istituzione). Replica, verifica e mantiene disponibilità.

  • Scopo: affidabilità rete e replicazione
  • Vincolo: controlli fail-closed + baseline
  • Interfacce: OpenAPI + registri append-only

Principio di rete (hash-only)

La rete non pubblica dati personali: pubblica solo prove minimizzate.
Pubblico: label + territorio + hash + timestamp · Privato: file release/licenze conservati localmente.

Questa scelta è deliberata: riduce superficie GDPR e rende la verifica ripetibile senza custodia dati.
