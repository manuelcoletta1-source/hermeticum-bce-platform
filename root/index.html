Root Manifest (genesis) — rete Hermeticum

Questo documento definisce la configurazione “root” della rete federata: policy, doppia root (umano + AI), regola di verifica fail-closed e ancoraggi crittografici. È un file infrastrutturale e tecnico.

Scarica EU_OPERATIONAL_ROOT.json Apri Registry Apri VERIFY

Nota: “Banca cibernetica europea” è definizione infrastrutturale/tecnologica. Non è istituto bancario o finanziario.

Regola di verifica

RULE: REGISTRY_MATCH && ROOT_VALID ? EXECUTE : BLOCK

  • REGISTRY_MATCH: l’identità deve avere match nel registry pubblico (hash-only).
  • ROOT_VALID: la root deve essere coerente con policy e ancoraggi.
  • Fail-closed: se non matcha → blocco operativo.
